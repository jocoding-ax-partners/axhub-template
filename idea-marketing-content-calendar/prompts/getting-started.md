# 시작용 프롬프트 모음

이 앱은 콘텐츠 발행 캘린더예요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 콘텐츠를 하나 등록해 보고
달력의 그 날짜 칸에 채널 색으로 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 채널 바꾸기

```
채널에 틱톡과 링크드인을 추가해줘. 달력 색은 다른 채널과 겹치지 않게 골라 주고,
이미 배포된 DB 에도 그대로 적용되게 해줘.
```

## 3. 발행 알림

```
발행 예정일 하루 전 아침 9시(한국 시간)에 아직 "발행" 이 아닌 콘텐츠의 담당자에게 axhub 알림을 보내줘.
담당자는 지금 이름만 적혀 있으니, 등록할 때 팀원 이메일을 고를 수 있게 바꿔줘. (AXHUB.md §5 참고)
```

## 4. 달력에서 바로 옮기기

```
달력에서 콘텐츠를 다른 날짜로 끌어다 놓으면 발행 예정일이 바뀌게 해줘.
옮기기 전에 한 번 더 물어보고, 휴대폰에서는 지금처럼 상세 화면에서 고치게 둬줘.
```

## 5. 내보내기

```
목록 화면에 지금 걸러 본 조건 그대로 CSV 로 내려받는 버튼을 만들어줘.
엑셀에서 한글이 깨지지 않게 해주고, = 이나 + 로 시작하는 제목은 수식으로 읽히지 않게 막아줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 지우기가 서버(app/actions.ts)에서도 canDelete 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
