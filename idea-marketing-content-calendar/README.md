# 콘텐츠 발행 캘린더

블로그 · 인스타그램 · 유튜브 · 뉴스레터에 올릴 콘텐츠의 발행 일정, 담당자, 진행 상태를 팀이 함께 보는 달력 앱이에요.
로그인은 axhub 계정으로 하고, 콘텐츠는 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**로그인한 팀원 누구나**
- 콘텐츠를 등록해요: 제목, 채널, 발행 예정일, 담당자, 상태(기획 · 작성 중 · 검토 · 발행), 메모(선택).
- 월간 달력에서 발행 예정일마다 콘텐츠를 채널 색으로 봐요. 누르면 상세가 열려요. 발행을 마친 콘텐츠는 줄이 그어져 보여요.
- 목록에서 채널 · 상태로 걸러 보고, 제목이나 담당자 이름으로 찾아요.
- 상세 화면에서 내용을 고쳐요. 상태를 바꾸거나 일정을 옮길 때 써요.

**등록한 사람과 관리자**
- 콘텐츠를 지워요. 누르기 전에 한 번 더 물어봐요.

## 화면

| 메뉴 | 주소 | 하는 일 |
|---|---|---|
| 달력 | `/` | 월간 달력. 이전 달 · 다음 달로 옮겨 다녀요. 휴대폰에서는 칸에 색 점만 보이고, 아래 "이 달 일정" 에 날짜별로 펼쳐져요 |
| 목록 | `/list` | 채널 · 상태로 거르기, 제목 · 담당자 찾기. 한 쪽에 30건씩 |
| 콘텐츠 등록 | `/new` | 새 콘텐츠 등록. 등록하면 그 달 달력으로 가요 |
| (상세) | `/c/번호` | 내용 보기 · 고치기 · 지우기 |

채널 색은 블로그 파랑, 인스타그램 노랑, 유튜브 빨강, 뉴스레터 초록이에요.

## 규칙

- 등록 · 수정은 로그인한 팀원 누구나 할 수 있어요. 담당자가 직접 상태를 바꾸는 팀 공용 달력이라서요.
- 두 사람이 같은 콘텐츠를 동시에 고치면, 나중에 저장한 사람에게 "그사이 다른 사람이 고쳤어요" 라고 알려 주고 덮어쓰지 않아요.
- 지우기는 등록한 사람과 관리자만 할 수 있어요. 지우면 되돌릴 수 없어요.
- 담당자는 이름을 적는 칸이에요. 등록할 때 내 이름이 미리 채워져요.
- 한 날에 콘텐츠가 많으면 달력 칸에는 3건만 보이고 "+N건 더" 를 누르면 그날 목록이 열려요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서 관리자가 하는 일은 **남이 등록한 콘텐츠도 지우는 것** 하나예요.

이 앱에서만 관리자 역할을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 남이 등록한 콘텐츠를 지울 수 있게 해줘. `lib/content.ts` 의 canDelete 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 팀원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "콘텐츠를 지울 수 있는 관리자의 axhub 사용자 ID 목록을 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`contents` 표 하나에 콘텐츠 한 건이 한 줄로 저장돼요.
제목, 채널, 발행 예정일, 담당자, 상태, 메모, 등록한 사람(axhub 사용자 ID · 이름)과 시각, 마지막으로 고친 사람과 시각이에요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 수정은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 달력 · 입력 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
