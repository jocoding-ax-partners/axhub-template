# 법인카드 사용 내역

직원이 법인카드 사용 건마다 용도를 적고, 관리자가 월별로 부서별 합계를 보는 앱이에요.
로그인은 axhub 계정으로 하고, 사용 내역은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 카드 사용 건을 입력해요: 사용일 · 가맹점 · 금액 · 부서 · 용도. 부서는 지난번에 쓴 부서가 미리 채워지고, 다른 사람들이 쓴 부서 이름도 골라 쓸 수 있어요.
- 용도는 비워 둬도 돼요. 비워 둔 건은 목록에 **용도 미기재** 로 표시되고, 입력한 사람이 나중에 목록에서 채워요.
- 용도를 안 적은 건이 있으면 화면 위에 알림이 뜨고, 「모아 보기」 로 달과 상관없이 한 번에 모아 채울 수 있어요.
- 월을 골라 내 사용 건과 합계를 보고, 가맹점 · 부서 · 용도로 찾아요. 잘못 입력한 건은 지우고 다시 입력해요 (지우기 전에 한 번 더 물어봐요).

**관리자**
- 월을 고르면 **부서별 사용 합계와 전체 합계**, 건수, 용도 미기재 건수를 봐요.
- 그달 모든 사람의 사용 건을 보고, 「용도 미기재만」 으로 걸러 보거나 가맹점 · 부서 · 용도 · 입력한 사람으로 찾아요.
- 그달 사용 건을 CSV 로 내려받아 엑셀에서 열어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 사용 내역 | `/` | 로그인한 모든 사람. 자기가 입력한 건만 보여요 |
| 월별 합계 | `/summary` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |

## 규칙

- 금액은 1원부터 한 건에 1억 원까지, 원 단위 정수로 적어요. 쉼표는 자동으로 찍혀요.
- 사용일은 오늘(한국 시간)보다 뒤일 수 없어요. 월별 합계는 **사용일** 기준이에요.
- 부서 이름은 앞뒤 · 겹친 공백을 정리해서 저장해요. "영업팀" 과 "영업 팀" 은 다른 부서로 합산되니 자동완성에 뜨는 이름을 골라 쓰면 좋아요.
- 용도는 입력한 사람만 채울 수 있어요. 관리자도 다른 사람의 용도를 대신 적거나 지울 수 없어요.
- 이미 적은 용도 · 금액 · 부서는 고칠 수 없어요. 잘못 적었으면 지우고 다시 입력해요.
- 날짜는 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 월별 합계를 볼 사람(예: 재무 담당자)이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 월별 합계를 볼 수 있게 해줘. `lib/card.ts` 의 isAdmin 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "월별 합계를 볼 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`card_expenses` 표 하나에 사용 건 한 건이 한 줄로 저장돼요.
입력한 사람(axhub 사용자 ID · 이름 · 이메일), 사용일, 가맹점, 금액, 부서, 용도(비워 두면 빈칸), 입력 · 수정 시각이에요.
부서별 · 전체 합계는 따로 저장하지 않고 볼 때마다 더해서 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 입력 · 합계는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 입력 · 월 · CSV 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
