# 시작용 프롬프트 모음

이 앱은 법인카드 사용 내역 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 내 사용 내역 화면에서 용도를 비운 사용 건을 하나 입력해 보고
월별 합계 화면에 부서 합계와 "용도 미기재" 가 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 부서 목록 정하기

```
부서를 자유 입력 말고 관리자가 정한 목록에서만 고르게 해줘.
월별 합계 화면에 부서 목록을 넣고 빼는 곳을 만들고, 이미 입력된 부서 이름은 그대로 두어 줘.
```

## 3. 용도 미기재 알림

```
매달 25일 오전 10시(한국 시간)에 그달 용도를 안 적은 건이 있는 사람에게 axhub 알림을 보내줘.
알림에는 건수와 앱 주소를 넣어 줘. (AXHUB.md §5 참고)
```

## 4. 영수증 첨부

```
사용 건마다 영수증 사진(JPG·PNG·PDF, 10MB 이하)을 올릴 수 있게 해줘.
axhub 파일 저장(storage)을 켜고, 사진은 올린 사람과 관리자만 볼 수 있게 해줘.
```

## 5. 부서별 한도

```
부서마다 월 한도를 정할 수 있게 해줘. 월별 합계에서 한도를 넘은 부서는 빨간 글씨로 보여 주고,
한도 대비 몇 % 썼는지도 같이 보여줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 화면·CSV 가 서버에서도 isAdmin 으로 막혀 있나?
- 용도 채우기·지우기가 서버(lib/card-store.ts)에서 본인 건만 바뀌게 되어 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
