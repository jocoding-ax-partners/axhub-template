# 디자인 정본

세 템플릿이 같은 모양으로 보이게 하는 파일들이에요. **여기만 고치고 스크립트를 돌리세요.**

```bash
node scripts/sync-design.mjs          # 세 템플릿에 반영
node scripts/sync-design.mjs --check  # 다른 곳이 있으면 실패 (CI)
bash scripts/check-design.sh          # 생색·생크기 사용 검사
```

| 파일 | 내용 | 뿌려지는 곳 |
|---|---|---|
| `tokens.css` | 토큰(색·글자·모서리·레이아웃) + 뼈대·조각 클래스 | vite `src/styles/`, next `app/`, astro `src/styles/` |
| `tailwind-preset.js` | 토큰 → Tailwind 클래스 매핑 | vite, next (astro 는 Tailwind 미사용) |
| `../scripts/check-design.sh` | 규칙 검사 | 세 템플릿의 `scripts/` (배포 전 ci 로 실행) |

## 값의 출처

axhub 콘솔이 쓰는 `@jocoding-ax-partners/design-system` 기준으로 한 번 옮겨 왔어요.
토큰 이름도 콘솔과 같아서 콘솔 화면 코드를 그대로 참고할 수 있어요.

자동 동기화는 하지 않아요. 정본이 바뀌면 사람이 판단해서 값을 옮기고 스크립트를 돌립니다.
새로 만들어지는 앱이 그 시점의 값을 받으면 충분하고, 이미 배포된 앱까지 따라가게 할 필요는 없어요.

## 레이아웃

콘솔과 같은 골격이에요. 상단바가 전체 폭을 쓰고 그 아래를 사이드바와 본문이 나눠요.

| 값 | 콘솔과 동일 |
|---|---|
| 상단바 높이 | 60px |
| 사이드바 폭 | 244px |
| 본문 최대 폭 | 1280px |
| 본문 위·아래 여백 | 40px · 120px |
| 좌우 여백 | 20 / 32 / 40px (반응형) |
| 페이지 제목 | 32px 굵게 |
| 섹션 간격 | 40px |

콘솔의 테넌트 전환·알림·역할 전환은 여러 앱을 관리하는 콘솔 기능이라 템플릿에 넣지 않았어요.
사이드바 없이 상단바만 쓰는 형태도 콘솔의 정식 모드예요 (앱 플랫폼이 꺼진 테넌트의 사용자 화면).

## 다크 모드

`<html data-theme="dark">` 를 붙이면 토큰 값이 통째로 바뀌어요. 클래스는 그대로 둡니다.
속성이 없으면 시스템 설정(`prefers-color-scheme`)을 따라가요.
