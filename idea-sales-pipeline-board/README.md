# 영업 파이프라인

영업 거래를 카드로 만들고, 단계 열(접촉 → 제안 → 협상 → 계약 → 실패)로 옮기며 관리하는 보드예요.
로그인은 axhub 계정으로 하고, 거래는 이 앱 전용 axhub DB 에 저장돼요. 팀원 모두가 같은 보드를 함께 봐요.

## 할 수 있는 일

- 거래(고객사 · 예상 금액 · 담당자 · 예상 계약일)를 카드로 만들어요. 담당자는 처음에 내 이름으로 채워져요.
- 카드를 다른 단계 열로 **끌어다 놓거나**, 카드 아래 **◀ ▶ 버튼**으로 이웃 단계로, **「옮기기」**로 원하는 단계로 한 번에 옮겨요.
  휴대폰에서는 열을 옆으로 넘겨 보고, 버튼으로 옮겨요.
- 단계마다 카드 수와 예상 금액 합계가 열 위에 보여요. 화면 위에는 진행 중(접촉 · 제안 · 협상) · 계약 · 실패 합계가 보여요.
- 예상 계약일이 지났는데 아직 진행 중인 거래는 날짜가 빨갛게 "지남" 으로 보여요.
- 고객사 · 담당자 이름으로 찾아요. 찾으면 열 위 건수 · 합계도 찾은 거래 기준으로 바뀌어요.
- 카드의 고객사 이름을 누르면 내용을 고칠 수 있어요. 지우기는 그 거래를 등록한 사람과 관리자만 할 수 있어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 보드 | `/` | 로그인한 모든 사람 |
| 거래 목록 | `/deals` | 로그인한 모든 사람. 단계별 탭 · 검색 · 30개씩 쪽 나눔 |
| 새 거래 | `/deals/new` | 로그인한 모든 사람 |
| 거래 고치기 | `/deals/번호` | 로그인한 모든 사람 (지우기 버튼은 등록한 사람 · 관리자에게만 보여요) |

보드의 한 열에는 카드가 30장까지 보여요. 더 있으면 열 아래 "N건 더 보기" 를 눌러 거래 목록에서 봐요.
열 위 건수 · 합계는 안 보이는 카드까지 모두 더한 값이에요.

## 규칙

- 예상 금액은 원 단위 정수예요 (쉼표는 넣어도 돼요). 한 건에 100조 원까지 적을 수 있어요.
- 예상 계약일은 비워 둘 수 있어요.
- 진행 중인 열은 예상 계약일이 빠른 순, 계약 · 실패 열은 최근에 옮긴 순으로 보여요.
- 두 사람이 같은 카드를 동시에 옮기면 먼저 옮긴 쪽이 반영되고, 나중에 옮긴 사람에게는 "다른 사람이 먼저 옮긴 거래예요" 가 보이고 최신 위치로 다시 그려져요.
- 지운 거래는 되돌릴 수 없어요. 놓친 거래는 지우기보다 「실패」 로 옮겨 두는 게 좋아요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서 관리자가 더 할 수 있는 일은 **다른 사람이 등록한 거래도 지우는 것** 하나예요. 등록 · 고치기 · 단계 옮기기는 누구나 해요.

이 앱에서만 관리자 일을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 관리자처럼 거래를 지울 수 있게 해줘. `lib/pipeline.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 영업팀 전체를 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "관리자로 둘 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`deals` 표 하나에 거래 한 건이 한 줄로 저장돼요.
고객사, 예상 금액, 담당자 이름, 예상 계약일, 단계, 등록한 사람(axhub 사용자 ID · 이름), 마지막으로 바꾼 사람 이름, 등록 · 수정 시각이에요.
단계별 건수 · 합계는 따로 저장하지 않고 매번 더해서 보여 줘요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 사용은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 파이프라인 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
