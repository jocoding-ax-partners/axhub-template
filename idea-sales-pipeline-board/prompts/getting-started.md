# 시작용 프롬프트 모음

이 앱은 영업 파이프라인 보드예요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 보드에서 거래를 하나 만들어
접촉 → 제안으로 옮겨 보고, 열 위 건수와 합계가 바뀌는지 어디서 보면 되는지 알려줘.
```

## 2. 카드에 칸 더하기

```
거래 카드에 메모와 고객 담당자 연락처 칸을 추가해줘.
보드 카드에는 메모 첫 줄만 보이게 하고, 고치기 화면에서 전체를 고칠 수 있게 해줘.
```

## 3. 가중 예상 매출

```
단계별 성공 확률(접촉 10%, 제안 30%, 협상 60%, 계약 100%, 실패 0%)을 정해 두고
예상 금액 × 확률을 더한 "가중 예상 매출" 을 보드 위 요약 카드에 보여줘.
```

## 4. 계약 알림

```
거래가 계약 단계로 옮겨지면 앱 관리자에게 axhub 알림을 보내줘.
알림에는 고객사와 금액, 옮긴 사람 이름을 넣어줘. (AXHUB.md §5 참고)
```

## 5. 기간으로 거르기

```
보드 위에 "이번 달 · 이번 분기 · 전체" 를 고르는 버튼을 넣고,
예상 계약일 기준으로 카드와 열 위 합계를 걸러줘. 날짜는 한국 시간 기준으로.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 지우기가 서버(app/actions.ts · lib/pipeline-store.ts)에서도 등록한 사람 · 관리자만 되게 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
