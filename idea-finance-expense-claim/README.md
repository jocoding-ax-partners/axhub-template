# 경비 정산

직원이 쓴 경비를 올리고, 관리자가 승인·반려한 뒤 월별 정산표를 엑셀(CSV)로 내려받는 앱이에요.
axhub 로그인 · axhub DB · axhub 파일 저장소 위에서 돌아가서 따로 준비할 서버나 계정이 없어요.

## 할 수 있는 일

| 누가 | 무엇을 |
|---|---|
| 직원 | 경비 올리기 — 사용일 · 항목(식대 / 교통 / 소모품 / 기타) · 금액 · 메모 · 영수증 사진 |
| 직원 | 내가 올린 경비와 처리 상태(대기 · 승인 · 반려) 보기, 승인 전 경비 지우기 |
| 관리자 | 월을 골라 직원별 경비 보기(30건씩 쪽 나눔), 영수증 사진 확인, 승인 · 반려 (본인 경비 제외, 결정을 바꾸면 한 번 더 묻고 마지막 처리자·시각을 남겨요) |
| 관리자 | 월별 정산표(직원별 승인 금액 합계) 보기, CSV 내려받기 |

## 화면

- **내 경비** (`/`) — 위쪽은 올리기 폼, 아래쪽은 내가 올린 경비 목록이에요.
- **승인 · 정산** (`/admin`) — 관리자만 열려요. 맨 위에서 월을 고르면 그 달의 정산표와 직원별 경비가 나와요.
  - 정산표에는 **승인된** 경비만 더해져요. 월은 경비를 쓴 날(사용일) 기준이에요.
  - CSV 는 한국어 엑셀에서 더블클릭으로 바로 열려요 (한글이 깨지지 않아요).

## 누가 관리자인가요

이 앱의 관리자는 axhub 가 정해 줘요. 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람 (앱 소유자)
- 워크스페이스 관리자

경비 승인만 맡기려고 누군가를 **워크스페이스 관리자로 올리지 마세요** — 회사 전체 권한이 함께 넘어가요.
이 앱에서만 관리자를 맡기려면 이렇게 해요.

1. 앱을 `내부공개` 로 두면 회사 사람은 모두 직원(`app_role` = `tenant_member`)으로 들어와요.
2. 관리자를 맡길 사람만 앱 초대로 따로 불러요 (`axhub access invite --app <슬러그> --user <사용자ID> --execute`). 초대받은 사람은 `app_role` 이 `app_member` 가 돼요.
3. Claude 에게 이렇게 부탁해요.
   > "`lib/expenses.ts` 의 `isAppAdmin()` 에서 `app_role` 이 `app_member` 인 사람도 관리자로 봐줘. 화면·CSV·승인 액션 모두 그 함수만 쓰게 유지해줘."

⚠️ `일부공개` 앱은 직원도 초대로 들어오므로 모두 `app_member` 예요 — 그때는 이 방법 대신 관리자 이메일 목록을 두는 쪽을 Claude 에게 부탁해요.
나머지 로그인한 사람은 모두 직원으로 써요. 관리자도 **본인 경비는 직접 승인·반려할 수 없어요** — 다른 관리자가 처리해요. 관리자가 아닌 사람이 `/admin` 주소를 직접 열어도 "관리자만 볼 수 있어요" 만 보여요.

직원이 앱에 들어오게 하려면 공개 범위를 정해요. 회사 전체면 `내부공개`, 몇 명만이면 `일부공개` 후 초대해요 — [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위).

## 저장되는 데이터

| 무엇 | 어디에 |
|---|---|
| 경비 내용 (사용일 · 항목 · 금액 · 메모 · 상태 · 올린 사람 이름과 이메일) | axhub DB (이 앱 전용) |
| 영수증 사진 | axhub 파일 저장소 (비공개) |

- 영수증 사진은 **올린 본인과 관리자만** 볼 수 있어요. 공개 주소가 없고, 볼 때마다 5분만 열리는 주소를 새로 만들어요.
- 사진은 JPG · PNG · WEBP, 10MB 이하만 올라가요. 아이폰에서 고른 사진은 보통 JPG 로 바뀌어 올라가요.
- 처음 열 때 필요한 표를 앱이 스스로 만들어요. 따로 할 일이 없어요.
- 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 내 컴퓨터에서 돌려 보기 (선택)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 DB 띄우기 (Docker 필요) → .env.local 의 DATABASE_URL 주석 해제
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 "로그인이 필요해요" 화면까지만 보여요. 실제 사용은 배포한 주소에서 확인해요.
검사 명령: `npm run check:design` (디자인 규칙) · `npm run check:logic` (금액·날짜·CSV 규칙).
