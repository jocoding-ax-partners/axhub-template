# 비품 신청·재고

직원이 필요한 비품을 신청하고, 관리자가 지급하면 재고에서 빠지는 앱이에요.
재고가 최소 재고 아래로 내려간 비품은 목록 맨 위에 **부족** 으로 표시돼요.
로그인은 axhub 계정으로 하고, 비품과 신청 내용은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 비품 목록에서 재고를 보고, 비품마다 수량과 메모(선택)를 적어 신청해요. 지금 재고보다 많이 신청하면 "입고된 뒤에 지급될 수 있어요" 라고 알려 줘요.
- 내 신청에서 상태(대기 · 지급 · 반려)와 반려 사유를 봐요.

**관리자**
- 비품 관리에서 비품(이름 · 현재 재고 · 최소 재고)을 등록하고, 들어온 수량만큼 입고해요. 이름과 최소 재고는 나중에 고칠 수 있어요.
- 신청 처리에서 대기 중인 신청을 먼저 들어온 순서로 보고, 지급하거나 사유를 적어 반려해요. 누르기 전에 한 번 더 물어봐요.
- 지급하면 그 수량만큼 재고에서 바로 빠져요. 재고가 모자라면 지급되지 않고 "재고가 모자라요" 가 보여요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 비품 | `/` | 로그인한 모든 사람 — 재고 현황 · 재고 목록 · 신청 |
| 내 신청 | `/my` | 로그인한 모든 사람 |
| 신청 처리 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |
| 비품 관리 | `/supplies` | 관리자만 — 등록 · 입고 · 이름/최소 재고 고치기 |

## 재고 규칙

- **부족** = 재고가 최소 재고보다 적을 때예요 (같으면 아직 부족이 아니에요). 최소 재고를 0 으로 두면 부족 표시를 하지 않아요.
- 재고는 **입고하면 늘고, 지급하면 줄어요.** 신청만으로는 줄지 않아요.
- 재고가 신청 수량보다 적으면 지급할 수 없어요. 입고한 뒤 지급하거나 반려해요.
- 같은 이름의 비품은 하나만 등록할 수 있어요 (대소문자 · 띄어쓰기 차이는 같은 이름으로 봐요).
- 한 번 지급하거나 반려하면 되돌릴 수 없어요.
- 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

관리자도 **본인 신청은 스스로 지급하거나 반려할 수 없어요.** 다른 관리자가 처리해요.

이 앱에서만 비품 관리를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 비품 관리와 신청 처리를 할 수 있게 해줘. `lib/supply.ts` 의 isAdmin 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "비품 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

표 두 개에 저장돼요.

- `supplies` — 비품 한 종류가 한 줄. 이름, 현재 재고, 최소 재고, 등록·수정 시각.
- `supply_requests` — 신청 한 건이 한 줄. 신청자(axhub 사용자 ID · 이름 · 이메일), 비품, 수량, 메모, 상태, 반려 사유, 처리한 사람과 시각.

"부족" 여부와 지급 대기 수량은 따로 저장하지 않고 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 신청 · 지급은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 비품 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
