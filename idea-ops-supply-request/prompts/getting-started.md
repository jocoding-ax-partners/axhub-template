# 시작용 프롬프트 모음

이 앱은 비품 신청·재고 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 비품 관리에서 비품을 하나 등록하고,
비품 화면에서 신청한 뒤 신청 처리 화면에 그 신청이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 부족 알림

```
지급해서 재고가 최소 재고 아래로 내려가면 앱 관리자에게 axhub 알림을 보내줘.
알림에는 비품 이름과 남은 재고를 넣어 줘. (AXHUB.md §5 참고)
```

## 3. 단위 · 분류

```
비품마다 단위(개 · 박스 · 롤)와 분류(사무용품 · 탕비실 · 청소용품)를 정할 수 있게 해줘.
비품 화면에서 분류로 거를 수 있게 하고, 이미 있는 비품은 단위 "개", 분류 "기타" 로 둬줘.
```

## 4. 입고 · 지급 이력

```
비품별로 입고와 지급 기록(언제, 누가, 몇 개)을 볼 수 있는 이력 화면을 만들어줘.
이력은 30개씩 나눠 보여 주고, 기간으로 거를 수 있게 해줘.
```

## 5. 신청 취소

```
대기 중인 내 신청은 직원이 직접 취소할 수 있게 해줘. 누르기 전에 한 번 더 물어봐 줘.
이미 지급되거나 반려된 신청은 취소할 수 없게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isAdmin 으로 막혀 있나?
- 지급이 재고 차감과 한 트랜잭션으로 묶여 있나? 재고가 음수가 될 수 있는 길이 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
