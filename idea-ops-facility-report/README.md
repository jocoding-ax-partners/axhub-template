# 시설 고장 신고

직원이 고장 난 곳을 사진과 위치로 신고하면, 담당자가 처리 상태를 바꾸고 메모를 남기는 앱이에요.
로그인은 axhub 계정으로 하고, 신고 내용은 이 앱 전용 axhub DB 에, 사진은 axhub 파일 저장소에 저장돼요.

## 할 수 있는 일

**직원**
- 위치, 고장 내용, 사진(1장 · 선택)을 적어 신고해요. 휴대폰에서는 사진을 바로 찍어 올릴 수 있어요.
- 내 신고 목록에서 상태(접수 · 처리 중 · 완료)와 담당자의 처리 메모를 봐요.

**담당자**
- 신고 관리 화면에서 접수 · 처리 중 · 완료 · 전체 탭으로 신고를 나눠 봐요. 탭마다 처리할 건수가 보여요.
- 위치 · 내용 · 신고자 이름 · 이메일로 신고를 찾아요.
- 신고마다 상태를 바꾸고 처리 메모를 남겨요. 저장하면 신고한 직원의 목록에 바로 보여요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 고장 신고 | `/` | 로그인한 모든 사람 (새 신고 · 내 신고) |
| 신고 관리 | `/admin` | 담당자만. 다른 사람이 열면 "담당자만 볼 수 있어요" 가 보여요 |

## 신고 규칙

- 위치는 100자, 내용은 1,000자, 처리 메모는 1,000자까지 적어요.
- 사진은 한 장, JPG · PNG · WEBP, 10MB 이하예요. 파일 이름이 아니라 파일 내용으로 진짜 사진인지 확인해요.
- 사진은 신고한 본인과 담당자만 볼 수 있어요. 누를 때마다 5분 동안만 열리는 주소로 보여 줘요.
- 상태는 담당자가 언제든 바꿀 수 있어요 (완료했다가 다시 처리 중으로 되돌리는 것도 돼요). 마지막으로 처리한 담당자와 시각이 함께 보여요.
- 두 담당자가 같은 신고를 동시에 고치면 나중에 저장한 쪽은 "다른 담당자가 먼저 고쳤어요" 가 떠요. 새로고침한 뒤 다시 저장해요.
- 목록은 한 쪽에 30건씩 보여요. 시각은 모두 한국 시간이에요.

## 담당자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 담당자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 신고 처리를 맡길 사람(예: 시설팀)이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 신고 관리를 할 수 있게 해줘. `lib/facility.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 담당자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "신고 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 담당자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`facility_reports` 표 하나에 신고 한 건이 한 줄로 저장돼요.
신고자(axhub 사용자 ID · 이름 · 이메일), 위치, 내용, 사진 파일 위치, 상태, 처리 메모, 마지막으로 처리한 담당자와 시각, 신고 시각이에요.
사진 파일 자체는 비공개 파일 저장소의 `reports/` 아래에 저장돼요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 신고 · 처리는 axhub 에 배포한 뒤 확인해요.
파일 저장소 값(`STORAGE_*`)이 없으면 사진 칸 없이 동작해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 파일 저장소 · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 신고 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
