# 시작용 프롬프트 모음

이 앱은 시설 고장 신고 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 고장 신고 화면에서 사진을 붙여 신고를 하나 올려 보고
신고 관리 화면에서 상태를 "처리 중" 으로 바꾸면 내 신고 목록에 어떻게 보이는지 확인하는 방법을 알려줘.
```

## 2. 알림 붙이기

```
새 신고가 들어오면 앱 관리자(담당자)에게 axhub 알림을 보내고,
담당자가 상태를 바꾸면 신고한 직원에게 바뀐 상태와 처리 메모를 알림으로 보내줘. (AXHUB.md §5 참고)
```

## 3. 위치를 골라서 신고하기

```
위치를 직접 적는 대신 건물 → 층 → 장소를 골라서 신고하게 해줘.
건물·층·장소 목록은 신고 관리 화면에서 담당자가 추가·삭제할 수 있게 하고, 목록에 없으면 직접 적을 수도 있게 해줘.
```

## 4. 긴급도

```
신고할 때 긴급 · 보통 중에 고르게 해줘. 신고 관리의 접수·처리 중 탭에서는 긴급한 신고를 맨 위에 보여 주고
긴급 신고에는 눈에 띄는 표시를 붙여줘.
```

## 5. 신고 취소

```
아직 접수 상태인 내 신고는 직원이 직접 취소할 수 있게 해줘. 누르기 전에 한 번 더 물어봐 주고,
취소하면 저장소의 사진도 같이 지워줘. 처리 중이거나 완료된 신고는 취소할 수 없게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 담당자만 해야 하는 동작이 서버(app/actions.ts · app/photos)에서도 isManager 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- 사진 주소가 화면이나 로그에 그대로 남는 곳이 있나?
- console.log 남은 거 있나?
```
