# 시작용 프롬프트 모음

이 앱은 부서 예산 현황 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 부서 · 예산 관리 화면에서 부서 하나를 만들고
올해 예산을 등록한 뒤, 집행 내역에서 집행 건을 넣으면 예산 현황 표가 어떻게 바뀌는지 어디서 보면 되는지 알려줘.
```

## 2. 강조 기준 바꾸기

```
집행률 강조 기준을 90% 말고 80% 로 바꿔줘. 그리고 100% 를 넘은 부서는 "초과" 로 따로 표시해줘.
```

## 3. 알림 붙이기

```
어떤 부서의 집행률이 90% 를 처음 넘으면 앱 관리자와 그 부서 담당자에게 axhub 알림을 보내줘. (AXHUB.md §5 참고)
같은 해에 같은 부서로 두 번 보내지는 않게 해줘.
```

## 4. CSV 내려받기

```
예산 현황 표와 그해 집행 내역을 CSV 로 내려받는 버튼을 추가해줘.
엑셀에서 한글이 깨지지 않게 해 주고, 관리자만 내려받을 수 있게 해줘.
```

## 5. 집행 건 고치기

```
집행 건을 지우지 않고 고칠 수 있게 해줘. 넣은 사람과 관리자만 고칠 수 있게 하고,
누가 언제 고쳤는지 남겨줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isBudgetAdmin 으로 막혀 있나?
- 부서 담당자가 아닌 사람이 집행 건을 넣을 수 없게 서버에서 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
