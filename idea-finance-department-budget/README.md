# 부서 예산 현황

관리자가 부서별 연간 예산을 등록하고, 부서 담당자가 집행 건(날짜 · 내용 · 금액)을 넣으면
부서마다 예산 · 집행액 · 남은 예산 · 집행률을 표로 보여 주는 앱이에요. 집행률이 90% 이상인 부서는 빨갛게 강조돼요.
로그인은 axhub 계정으로 하고, 데이터는 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**모든 사람 (로그인)**
- 연도별로 부서마다 예산 · 집행액 · 남은 예산 · 집행률을 표로 봐요. 맨 위에는 전체 합계가 있어요.
- 집행률 90% 이상인 부서는 빨간 글자와 「주의」 표시로 강조돼요.
- 그해 집행 내역을 보고 내용 · 부서 · 넣은 사람으로 찾아요.

**부서 담당자**
- 담당 부서의 집행 건을 날짜 · 내용 · 금액으로 넣어요. 넣으면 바로 예산 현황에 반영돼요.
- 내가 넣은 집행 건은 지울 수 있어요. 지우기 전에 한 번 더 물어봐요.

**관리자**
- 부서를 만들고, 부서마다 연간 예산을 등록하거나 고쳐요.
- 부서 담당자를 이메일로 지정하거나 빼요.
- 모든 부서의 집행 건을 넣고 지울 수 있어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 예산 현황 | `/` | 로그인한 모든 사람 |
| 집행 내역 | `/expenses` | 로그인한 모든 사람이 봐요. 입력은 부서 담당자와 관리자만 |
| 부서 · 예산 관리 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |

화면 오른쪽 위 ‹ › 버튼으로 연도를 바꿔요.

## 예산 규칙

- 남은 예산 = 연간 예산 − 그해 집행액, 집행률 = 집행액 ÷ 예산 × 100 (소수 첫째 자리까지).
- 집행 건은 **집행 날짜의 연도** 예산에서 빠져요. 그해 예산이 등록된 부서에만 넣을 수 있어요.
- 오늘(한국 시간)보다 뒤의 날짜는 넣을 수 없어요.
- 예산을 넘겨 집행해도 막지 않아요. 남은 예산이 마이너스로, 집행률이 100% 넘게 보여요.
- 예산이 0원인 부서에 집행 건이 있으면 집행률 100% 로 보고 강조해요.
- 집행 건이 남아 있는 부서는 지울 수 없어요. 부서를 지우면 그 부서의 모든 연도 예산과 담당자 지정도 함께 지워져요.

## 관리자와 부서 담당자는 누구인가요

**관리자**는 axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

**부서 담당자**는 관리자가 「부서 · 예산 관리」 화면에서 부서마다 이메일로 지정한 사람이에요.
그 이메일로 axhub 에 로그인하면 그 부서 집행 건을 넣을 수 있어요. 한 사람이 여러 부서를 맡아도 돼요.

이 앱에서만 예산 관리를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 부서 · 예산 관리를 할 수 있게 해줘. `lib/budget.ts` 의 isBudgetAdmin 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 부서 담당자도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "부서 · 예산 관리를 할 수 있는 사람의 이메일 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

부서 담당자가 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

표 4개에 저장돼요.

- `departments` — 부서 이름
- `department_managers` — 부서마다 담당자 이메일
- `budgets` — 부서 · 연도마다 예산 금액, 마지막으로 고친 사람과 시각
- `expenses` — 집행 건 한 건이 한 줄 (부서, 집행 날짜, 내용, 금액, 넣은 사람의 axhub 사용자 ID · 이름, 넣은 시각)

집행액 · 남은 예산 · 집행률은 따로 저장하지 않고 집행 건을 더해서 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 입력 · 관리는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 예산 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
