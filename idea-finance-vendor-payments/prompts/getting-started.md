# 시작용 프롬프트 모음

이 앱은 거래처 지급 일정 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 지급 일정 화면에서 이번 주 금요일 지급 건을 하나 등록해 보고,
홈의 "이번 주 지급 예정" 합계에 잡히는지 어디서 확인하면 되는지 알려줘.
```

## 2. 지급 알림

```
지급 예정일 하루 전 아침 9시(한국 시간)에 아직 지급하지 않은 건을 모아서
앱 관리자에게 axhub 알림으로 보내줘. 지급 지연 건이 있으면 같이 알려줘. (AXHUB.md §5 참고)
```

## 3. 매달 반복되는 지급

```
임대료처럼 매달 같은 날 나가는 지급은 "매월 반복" 을 켜서 등록할 수 있게 해줘.
지급 완료로 바꾸면 다음 달 같은 날 지급 건이 자동으로 하나 생기게 하고, 반복을 끄는 버튼도 둬줘.
```

## 4. 엑셀로 내려받기

```
지급 일정 화면에서 지금 보고 있는 목록(탭 · 검색 조건 그대로)을 CSV 로 내려받게 해줘.
엑셀에서 한글이 안 깨지게 하고, = + - @ 로 시작하는 칸은 수식으로 실행되지 않게 막아줘.
```

## 5. 거래처 계좌 정보

```
거래처마다 은행 이름 · 계좌번호 · 예금주를 저장할 수 있게 해줘. 거래처 화면에서 관리자만 보고 고칠 수 있게 하고,
지급 완료 버튼 옆에 그 거래처 계좌를 보여줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작(지급 완료 · 지급 취소)이 서버(app/actions.ts)에서도 isManager 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- 목록 쿼리에 LIMIT 이 빠진 곳이 있나?
- console.log 남은 거 있나?
```
