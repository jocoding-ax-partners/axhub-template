# 거래처 지급 일정

거래처에 보낼 돈의 지급 예정일과 금액을 정리하고, 이번 주에 지급할 건과 밀린 지급을 한눈에 보는 앱이에요.
로그인은 axhub 계정으로 하고, 지급 건은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**로그인한 모든 사람**
- 지급 건(거래처, 금액, 지급 예정일, 메모)을 등록해요. 거래처 이름은 전에 적은 이름이 자동완성으로 떠요.
- 홈에서 이번 주(월~일) 지급 예정 건과 합계, 예정일이 지났는데 아직 지급하지 않은 건을 봐요.
- 지급 일정에서 미지급 · 지급 지연 · 지급 완료 · 전체로 나눠 보고, 거래처나 메모로 찾아요.
- 거래처별로 미지급 합계 · 지급 완료 합계 · 마지막 지급일과 지급 이력을 봐요.
- 내가 등록한 건은 지급 전까지 고치거나 지울 수 있어요. 지우기 전에 한 번 더 물어봐요.

**관리자**
- 지급한 건을 "지급 완료" 로 바꾸고 실제 지급일을 남겨요. 지급일은 오늘보다 뒤로 고를 수 없어요.
- 잘못 누른 지급 완료는 "지급 취소" 로 되돌려요 (한 번 더 물어봐요).
- 다른 사람이 등록한 건도 고치거나 지울 수 있어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 이번 주 지급 | `/` | 로그인한 모든 사람 |
| 지급 일정 | `/payments` | 로그인한 모든 사람. 지급 건 등록도 여기서 해요 |
| 거래처 | `/vendors` | 로그인한 모든 사람. 거래처를 누르면 그 거래처의 지급 이력이 보여요 |

지급 완료 · 지급 취소 버튼은 관리자에게만 보이고, 서버에서도 한 번 더 막아요.

## 지급 규칙

- 한 주는 **월요일부터 일요일까지**예요.
- **이번 주 지급 예정** = 아직 지급하지 않은 건 중 예정일이 오늘 ~ 이번 주 일요일인 건이에요.
- **지급 지연** = 아직 지급하지 않았는데 예정일이 오늘보다 앞인 건이에요. 두 목록은 겹치지 않아요.
- **이번 주 지급 완료** = 지급일이 이번 주 월요일 ~ 오늘인 건이에요.
- 금액은 원 단위 정수로, 한 건에 1,000억 원까지 적을 수 있어요.
- 지급 완료한 건은 고치거나 지울 수 없어요. 고쳐야 하면 관리자가 지급 취소를 한 뒤 고쳐요.
- 거래처 이름의 앞뒤 공백과 겹친 공백은 정리해서 저장해요 ("한빛  상사" → "한빛 상사").
- 날짜는 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 지급 처리를 맡길 사람(예: 재무 담당자)이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 지급 처리를 할 수 있게 해줘. `lib/payment.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 다른 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "지급 처리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`vendor_payments` 표 하나에 지급 건 한 건이 한 줄로 저장돼요.
거래처, 금액, 지급 예정일, 메모, 지급일(비어 있으면 미지급), 지급 처리한 사람과 시각, 등록한 사람(axhub 사용자 ID · 이름)이에요.
합계와 거래처별 이력은 따로 저장하지 않고 이 표에서 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 지급 처리는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 지급 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
