# 시작용 프롬프트 모음

이 앱은 장비 대여 관리 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 장비 관리 화면에서 장비를 하나 등록하고
장비 목록에서 빌려 보려면 어디를 누르면 되는지 알려줘.
```

## 2. 반납 알림

```
반납 예정일 하루 전과 반납 예정일이 지난 날 아침에 빌린 사람에게 axhub 알림을 보내줘.
지연된 대여는 관리자에게도 알려줘. (AXHUB.md §5 참고)
```

## 3. 장비별 기록

```
장비 이름을 누르면 그 장비의 대여 기록(누가 언제 빌리고 반납했는지)을 볼 수 있는 화면을 만들어줘.
기록은 30개씩 나눠서 보여줘.
```

## 4. 장비 정보 고치기

```
관리자가 장비 이름 · 종류 · 자산 번호를 고칠 수 있게 해줘.
자산 번호가 다른 장비와 겹치면 저장하지 말고 알려줘.
```

## 5. 대여 연장

```
빌린 사람이 반납 예정일을 한 번 늦출 수 있게 해줘. 오늘부터 90일 안에서만 고를 수 있게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isAdmin 으로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
