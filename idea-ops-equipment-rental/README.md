# 장비 대여 관리

노트북 · 카메라 같은 회사 장비를 누가 언제까지 빌렸는지 관리하는 앱이에요.
로그인은 axhub 계정으로 하고, 장비와 대여 기록은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 장비 목록에서 빌릴 수 있는 장비를 골라 반납 예정일을 넣고 대여해요.
- 다 쓰면 "반납" 을 눌러요. 누르기 전에 한 번 더 물어봐요.
- 장비 목록에서 지금 누가 빌렸는지, 반납 예정일이 언제인지 봐요. **반납 예정일이 지난 대여는 빨간색**으로 보여요.
- 이름 · 종류 · 자산 번호 · 빌린 사람으로 찾고, 전체 · 대여 가능 · 대여 중 · 반납 지연으로 골라 봐요.
- 내 대여에서 지금 빌린 장비와 지난 대여 기록을 봐요.

**관리자**
- 장비(이름 · 종류 · 자산 번호)를 등록해요.
- 더 이상 빌려주지 않는 장비는 목록에서 빼요. 지난 대여 기록은 남아요.
- 직원이 반납을 깜빡했으면 장비를 돌려받은 뒤 "대신 반납" 으로 처리해요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 장비 목록 | `/` | 로그인한 모든 사람 |
| 내 대여 | `/my` | 로그인한 모든 사람 |
| 장비 관리 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |

## 대여 규칙

- 장비 한 대는 한 번에 한 사람만 빌릴 수 있어요. 두 사람이 동시에 눌러도 한 사람만 빌려요.
- 반납 예정일은 오늘부터 90일 안에서 골라요. 예정일 당일까지는 정상이고, 다음 날부터 "반납 지연" 이에요.
- 반납은 빌린 본인이나 관리자만 할 수 있어요.
- 자산 번호는 장비마다 달라야 해요 (대소문자는 같은 것으로 봐요).
- 빌려 간 장비는 반납된 뒤에만 목록에서 뺄 수 있어요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 장비 관리를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 장비 관리를 할 수 있게 해줘. `lib/rental.ts` 의 isAdmin 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "장비 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

- `equipment` 표 — 장비 한 대가 한 줄이에요. 이름, 종류, 자산 번호, 등록한 시각, 목록에서 뺀 시각.
- `rentals` 표 — 대여 한 번이 한 줄이에요. 빌린 사람(axhub 사용자 ID · 이름 · 이메일), 반납 예정일, 빌린 시각, 반납한 시각과 반납 처리한 사람.

"지금 빌린 사람" 은 아직 반납하지 않은 대여 줄이에요. 따로 저장하지 않아요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 대여 · 반납은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 대여 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
