# 면접 일정·평가표

지원자별 면접 시간과 면접관 평가를 한곳에 모으는 앱이에요.
로그인은 axhub 계정으로 하고, 지원자와 평가는 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**채용 담당자**
- 지원자를 등록해요. 이름, 지원 직무, 면접 일시, 면접관 이메일(쉼표로 여러 명, 최대 10명)을 적어요.
- 지원자 목록을 이름 · 직무로 찾고, 결과(결과 대기 · 합격 · 보류 · 불합격)로 걸러 봐요.
- 지원자 상세에서 면접관들의 항목별 평균 점수와 의견을 모아 봐요. 아직 평가를 내지 않은 면접관도 보여요.
- 결과(합격 · 보류 · 불합격)를 기록해요. 누르기 전에 한 번 더 물어보고, 나중에 바꾸거나 지울 수 있어요.
- 면접 일정 · 면접관이 바뀌면 고치고, 잘못 등록한 지원자는 지워요.

**면접관**
- 「내 면접」 에서 내가 면접관으로 배정된 지원자를 봐요. 평가할 면접이 맨 위에 와요.
- 지원자마다 직무 역량 · 소통 · 문화 적합을 각각 1~5점으로 고르고 의견을 적어요.
- 결과가 기록되기 전까지는 내 평가를 다시 고칠 수 있어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 면접 | `/` | 로그인한 모든 사람 (내가 배정된 면접만 보여요) |
| 평가표 | `/interviews/번호` | 그 지원자에게 배정된 면접관만 |
| 지원자 관리 | `/candidates` | 채용 담당자만. 다른 사람이 열면 "채용 담당자만 볼 수 있어요" 가 보여요 |
| 지원자 상세 | `/candidates/번호` | 채용 담당자만 |

## 평가 규칙

- 면접관은 **axhub 로그인 이메일**로 알아봐요. 지원자를 등록할 때 면접관의 axhub 로그인 이메일을 그대로 적어 주세요 (대소문자는 상관없어요).
- 면접관은 서로의 점수와 의견을 볼 수 없어요. 서로에게 끌리지 않게, 모아 보기는 채용 담당자만 해요.
- 종합 점수는 세 항목의 평균이고, 지원자의 평균은 제출된 평가만으로 계산해요.
- 결과가 기록되면 면접관은 평가를 고칠 수 없어요. 결과를 지우면 다시 고칠 수 있어요.
- 이미 평가를 낸 면접관은 면접관 목록에서 뺄 수 없어요.
- 지원자를 지우면 그 지원자의 평가도 함께 지워지고 되돌릴 수 없어요.
- 날짜와 시각은 모두 한국 시간이에요.

## 채용 담당자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 채용 담당자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

채용 담당자도 면접관으로 배정되면 「내 면접」 에서 평가를 남길 수 있어요.

이 앱에서만 채용 담당자를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 지원자 관리를 할 수 있게 해줘. `lib/interview.ts` 의 isRecruiter 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 채용 담당자가 돼요. 면접관도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "지원자 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 채용 담당자로 두고."

면접관이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

- `candidates` — 지원자 한 명이 한 줄이에요. 이름, 지원 직무, 면접 일시, 면접관 이메일 목록, 결과와 기록한 사람 · 시각, 등록한 사람이에요.
- `scorecards` — 면접관 한 명이 지원자 한 명에게 낸 평가가 한 줄이에요. 면접관 이메일 · 이름, 세 항목 점수, 의견, 제출 · 수정 시각이에요.

평균은 따로 저장하지 않고 평가를 모아 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 평가는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 평가 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
