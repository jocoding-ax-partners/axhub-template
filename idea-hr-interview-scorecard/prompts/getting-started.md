# 시작용 프롬프트 모음

이 앱은 면접 일정·평가표 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 지원자 관리 화면에서 나를 면접관으로 지원자를 하나 등록해 보고,
내 면접 화면에서 평가를 남긴 뒤 지원자 상세에 평균이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 평가 항목 바꾸기

```
평가 항목에 '문제 해결력' 을 추가해줘. 1~5점으로 고르게 하고, 지원자 상세의 평균과 종합 점수에도 반영해줘.
이미 낸 평가는 새 항목이 비어 있어도 화면이 깨지지 않게 해줘.
```

## 3. 알림 붙이기

```
지원자를 등록하거나 면접 일시가 바뀌면 배정된 면접관에게 axhub 알림을 보내 주고,
면접관이 평가를 모두 내면 채용 담당자에게도 알려줘. (AXHUB.md §5 참고)
```

## 4. 이력서 첨부

```
지원자마다 이력서 PDF 를 하나 올릴 수 있게 해줘. 채용 담당자와 배정된 면접관만 내려받을 수 있게 하고,
파일은 axhub 파일 저장소에 넣어줘. (AXHUB.md 참고)
```

## 5. 면접 일정 모아 보기

```
지원자 관리 화면에 이번 주와 다음 주 면접 일정을 날짜별로 모아 보는 표를 추가해줘. 시각은 한국 시간으로.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 채용 담당자만 해야 하는 동작이 서버(app/actions.ts)에서도 isRecruiter 로 막혀 있나?
- 면접관이 남의 평가를 볼 수 있는 화면이 생기지 않았나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
