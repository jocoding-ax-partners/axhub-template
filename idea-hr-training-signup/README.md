# 사내 교육 신청

관리자가 교육 일정을 올리면 직원이 신청하고, 정원이 차면 자동으로 마감되는 앱이에요.
로그인은 axhub 계정으로 하고, 교육과 신청 명단은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 다가오는 교육을 가까운 일시부터 보고, 제목 · 장소로 찾아요.
- 교육마다 일시 · 장소 · 설명과 **신청 인원 / 정원**이 보여요. 「신청하기」로 신청하고, 정원이 차면 버튼이 **「마감」**으로 바뀌어요.
- 「내 신청」에서 신청한 교육을 모아 보고, 교육이 시작하기 전까지 취소해요. 취소하기 전에 한 번 더 물어봐요.

**관리자**
- 교육(제목 · 설명 · 일시 · 장소 · 정원)을 등록해요. 등록하면 바로 직원 화면에 보여요.
- 교육별 신청자 명단을 보고(이름 · 이메일로 찾기), **CSV 로 내려받아요**. 엑셀에서 바로 열려요.
- 교육 정보를 고치거나, 취소된 교육을 지워요. 지울 땐 한 번 더 물어봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 교육 신청 | `/` | 로그인한 모든 사람 |
| 내 신청 | `/mine` | 로그인한 모든 사람 |
| 교육 관리 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |
| 교육 한 건 (명단 · CSV · 수정 · 지우기) | `/admin/교육번호` | 관리자만 |

## 신청 규칙

- 한 사람은 한 교육에 한 번만 신청할 수 있어요.
- 신청 인원이 정원에 닿으면 마감돼요. 여러 명이 동시에 눌러도 정원을 넘지 않아요. 누가 취소하면 다시 신청할 수 있어요.
- 교육 일시가 지나면 신청도 취소도 닫혀요. 지난 교육은 「내 신청」에 「지난 교육」으로 남아요.
- 정원은 1 ~ 1,000명이에요. 이미 신청한 인원보다 정원을 줄일 수는 없어요.
- 새 교육은 지금보다 뒤의 일시로만 등록해요. 이미 등록한 교육은 지난 교육이어도 고칠 수 있어요.
- 교육을 지우면 그 교육의 신청 명단도 함께 지워져요. 필요하면 먼저 CSV 로 내려받아 두세요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 교육 관리를 맡길 사람(예: 교육 담당자)이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 교육 관리를 할 수 있게 해줘. `lib/training.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "교육 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

표 두 개에 저장돼요.

- `trainings` — 교육 한 건이 한 줄: 제목, 설명, 일시, 장소, 정원, 등록한 사람, 등록 · 수정 시각.
- `training_signups` — 신청 한 건이 한 줄: 어떤 교육인지, 신청자(axhub 사용자 ID · 이름 · 이메일), 신청 시각. 취소하면 그 줄이 지워져요.

신청 인원은 따로 저장하지 않고 신청 줄을 세어서 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

- "관리자가 명단에서 출석을 체크하고, 출석 여부도 CSV 에 넣어줘"

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 신청은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 신청 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
