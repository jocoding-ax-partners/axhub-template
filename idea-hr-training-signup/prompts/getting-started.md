# 시작용 프롬프트 모음

이 앱은 사내 교육 신청 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 교육 관리 화면에서 교육을 하나 등록하고
교육 신청 화면에서 신청해 본 뒤, 명단 CSV 를 어디서 내려받는지 알려줘.
```

## 2. 대기자 받기

```
정원이 차면 「마감」 대신 「대기 신청」을 받을 수 있게 해줘.
누가 취소하면 대기 1번이 자동으로 신청자가 되고, 명단 화면에 대기자도 따로 보여줘.
```

## 3. 알림 붙이기

```
새 교육이 등록되면 직원들에게 axhub 알림을 보내고,
교육 하루 전에는 신청자에게 일시와 장소를 다시 알려줘. (AXHUB.md §5 참고)
```

## 4. 신청 마감일 따로 정하기

```
교육마다 신청 마감 일시를 따로 정할 수 있게 해줘. 비워 두면 지금처럼 교육 시작 시각에 닫혀.
교육 신청 화면에 "○월 ○일까지 신청" 도 보여줘.
```

## 5. 출석 체크

```
관리자가 신청자 명단에서 출석 여부를 체크할 수 있게 해줘.
CSV 에도 출석 열을 넣고, 교육 관리 목록에 출석 인원도 보여줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts, roster.csv 라우트)에서도 isManager 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
