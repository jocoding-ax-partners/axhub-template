# 시작용 프롬프트 모음

이 앱은 신규 입사자 온보딩 체크리스트 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 입사자 목록에서 입사자를 한 명 등록해 보고
체크리스트 5개가 붙었는지, 항목을 체크하면 목록의 진행률이 바뀌는지 어디서 확인하면 되는지 알려줘.
```

## 2. 우리 회사 기본 체크리스트로 바꾸기

```
기본 체크리스트를 우리 회사에 맞게 바꾸고 싶어. 화면의 「기본 체크리스트」 메뉴에서 바꾸면 되는지,
처음 배포할 때부터 다른 항목으로 시작하려면 어디를 고치면 되는지 알려줘. (lib/onboarding.ts 의 DEFAULT_ITEMS)
```

## 3. 항목 담당자 나누기

```
기본 체크리스트 항목마다 담당(IT · 인사 · 팀장)을 정할 수 있게 해줘.
입사자 화면에서 항목 옆에 담당이 보이고, 「내 담당」 메뉴에서는 내가 맡은 미완료 항목만 모아 보이게 해줘.
```

## 4. 알림 붙이기

```
입사일 3일 전까지 끝나지 않은 항목이 있으면 앱 관리자에게 axhub 알림을 보내줘.
매일 아침 9시(한국 시간)에 한 번만 확인하면 돼. (AXHUB.md §5 참고)
```

## 5. 완료한 사람 정리

```
체크리스트를 모두 끝낸 입사자는 목록에서 기본으로 숨기고, 「완료한 입사자 보기」 를 누르면 보이게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작(기본 항목 추가·삭제, 입사자 삭제)이 서버(app/actions.ts)에서도 isAdmin 으로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
