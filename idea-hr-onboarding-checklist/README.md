# 신규 입사자 온보딩 체크리스트

입사자별로 장비 · 계정 · 교육 항목을 체크하고 진행률을 보는 앱이에요.
로그인은 axhub 계정으로 하고, 입사자와 체크리스트는 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**담당자 (로그인한 모든 사람)**
- 입사자의 이름 · 부서 · 입사일을 적어 등록해요. 등록하면 기본 체크리스트(처음에는 노트북 지급 · 사내 계정 발급 · 보안 교육 · 부서 소개 · 첫 주 면담)가 자동으로 붙어요.
- 입사자 목록에서 사람마다 진행률(%)과 입사일까지 남은 날(D-3, 입사 5일째)을 봐요. 이름 · 부서로 찾을 수 있어요.
- 입사자를 누르면 항목마다 완료 체크와 메모를 남겨요. 체크는 누르는 즉시 저장되고, 누가 언제 고쳤는지 함께 보여요.
- 이름 · 부서 · 입사일을 잘못 적었으면 고쳐요.

**관리자**
- 「기본 체크리스트」 메뉴에서 항목을 추가하거나 지워요 (최대 30개). 지울 때는 한 번 더 물어봐요.
- 잘못 등록한 입사자를 지워요. 그 사람의 체크와 메모도 함께 지워지고, 되돌릴 수 없어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 입사자 목록 | `/` | 로그인한 모든 사람 — 현황 숫자 · 등록 · 목록(30명씩) · 검색 |
| (입사자 상세) | `/hires/번호` | 로그인한 모든 사람 — 목록에서 눌러 들어가요. 삭제 버튼은 관리자에게만 보여요 |
| 기본 체크리스트 | `/settings` | 누구나 볼 수 있고, 추가 · 삭제는 관리자만 |

## 규칙

- 기본 체크리스트는 **등록하는 순간 복사**돼요. 나중에 기본 항목을 바꿔도 이미 등록한 입사자의 체크리스트는 그대로예요.
- 진행률 = 완료한 항목 수 ÷ 그 입사자의 항목 수 (반올림). 다 끝나면 막대가 초록색으로 바뀌어요.
- 기본 항목이 하나도 없을 때 등록하면 빈 체크리스트가 붙고, 진행률 대신 "항목 없음" 으로 보여요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 기본 체크리스트를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 기본 체크리스트를 관리하고 입사자를 지울 수 있게 해줘. `lib/onboarding.ts` 의 isAdmin 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 담당자도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "기본 체크리스트를 관리할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

담당자가 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).
로그인한 사람은 모든 입사자를 볼 수 있으니, 인사 담당자만 쓰게 하려면 일부공개로 두고 그 사람들만 초대해요.

## 저장하는 데이터

| 표 | 한 줄 = | 내용 |
|---|---|---|
| `hires` | 입사자 한 명 | 이름 · 부서 · 입사일 · 등록한 사람(axhub 사용자 ID · 이름) · 등록 시각 |
| `hire_items` | 입사자의 체크 항목 하나 | 순서 · 항목 이름 · 완료 여부 · 메모 · 마지막으로 고친 사람과 시각 |
| `checklist_templates` | 기본 체크리스트 항목 하나 | 항목 이름 |
| `app_meta` | 내부 표시 | 기본 5개를 이미 넣었는지 (지운 항목이 다시 살아나지 않게) |

진행률은 따로 저장하지 않고 화면을 열 때마다 세요.
표와 기본 5개 항목은 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 체크는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 온보딩 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
