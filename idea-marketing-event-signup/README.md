# 이벤트 참가 신청 관리

세미나·설명회·네트워킹 같은 이벤트의 **참가 신청자 명단**을 모으고, **행사 당일 출석**을 체크하는 앱이에요.
axhub 로그인을 쓰고, 데이터는 axhub 가 붙여 주는 이 앱 전용 DB 에 저장돼요.

> axhub 로 할 수 있는 다른 일(알림·메일, 공개 범위, 도메인, 되돌리기 등)은 [AXHUB.md](./AXHUB.md) 에 모아 뒀어요.

## 무엇을 할 수 있나요

- **이벤트 만들기** — 이름, 일시(한국 시간), 장소, 정원을 적어요.
- **참가 신청자 등록** — 한 명씩(이름·회사·이메일) 넣거나, **CSV 파일로 한 번에** 올려요.
  - 엑셀에서 저장한 한글 CSV 를 그대로 올릴 수 있어요 (CSV UTF-8 · 일반 CSV 모두).
  - 등록 전에 **미리보기**로 줄마다 결과를 보여줘요: 등록 가능 · 입력 오류 · 파일 안 중복 · 이미 신청 · 정원 초과.
  - 같은 이벤트에 같은 이메일은 한 번만 들어가요 (대소문자 무시).
  - **정원을 넘지 않아요.** 남은 자리만큼만 위에서부터 등록하고, 넘친 사람은 "정원 초과" 로 알려 줘요.
- **당일 출석 체크** — 명단에서 이름을 검색해 「출석」을 눌러요. 잘못 눌렀으면 「출석 취소」.
- **현황** — 신청 인원 · 출석 인원 · 출석률(출석 ÷ 신청)을 이벤트마다 보여줘요.

## 화면

| 화면 | 주소 | 내용 |
|---|---|---|
| 이벤트 | `/` | 이벤트 목록(검색·쪽 나눔, 이벤트별 신청/출석 수) · 새 이벤트 만들기 |
| 이벤트 상세 | `/events/번호` | 현황 카드 3개 · 참가자 명단과 출석 체크(검색·쪽 나눔) · 신청자 등록(한 명 / CSV) · 이벤트 지우기 |

휴대폰(폭 375px)에서도 그대로 쓸 수 있어요. 행사장 입구에서 휴대폰으로 출석을 체크하면 돼요.

## 누가 쓸 수 있나요 — 담당자

신청자 개인정보(이름·회사·이메일)가 있어서 **담당자만** 화면을 보고 바꿀 수 있어요.

- **담당자 = axhub 가 "관리자" 로 알려 주는 사람**이에요: 이 앱을 만든 사람(소유자), 워크스페이스 관리자, 플랫폼 관리자.
- 다른 사람이 로그인하면 "담당자만 쓸 수 있어요" 안내만 보여요. 저장 기능도 서버에서 한 번 더 막아요.
- 앱 소유자와 워크스페이스 관리자는 따로 할 일 없이 담당자예요. 이 앱 하나 때문에 누군가를 워크스페이스 관리자로 만들 필요는 없어요.
- 동료에게 **이 앱에서만** 담당자 권한을 주려면: 그 사람을 이 앱에 초대하고(`axhub access invite --app <슬러그> --user <사용자ID> --execute`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
  Claude 에게 이렇게 부탁하세요 — "이 앱에 초대한 사람(`me().app_role` 이 있는 사람)도 `lib/manager.ts` 에서 담당자로 통과시켜줘."
- 참가자 본인이 직접 신청하는 화면은 없어요 (담당자가 등록해요).

## 저장되는 데이터

| 표 | 내용 |
|---|---|
| `events` | 이벤트 이름 · 일시 · 장소 · 정원 · 만든 사람 |
| `attendees` | 이벤트별 신청자 이름 · 회사 · 이메일 · 출석 시각 |

- 처음 열 때 표가 자동으로 만들어져요. 따로 할 일은 없어요.
- 이벤트를 지우면 그 이벤트의 신청자·출석 기록도 함께 지워져요 (지우기 전에 한 번 더 물어봐요).
- 백업·복원은 axhub 앱 콘솔의 백업 탭에서 해요.

## Claude 에게 이렇게 부탁해 보세요

이 폴더에서 Claude Code 를 열고 말로 요청하면 돼요.

- "이벤트 정보(이름·일시·장소·정원)를 고칠 수 있는 수정 화면을 만들어줘."
- "참가자 명단을 CSV 로 내려받는 버튼을 이벤트 상세에 추가해줘. 출석 여부와 출석 시각도 넣어줘."
- "신청자에게 연락처(전화번호) 칸을 추가해줘. CSV 로 올릴 때도 '연락처' 열을 읽게 해줘."
- "이 앱에 초대한 사람(`me().app_role` 이 있는 사람)도 담당자로 쓸 수 있게 해줘."
- "행사 하루 전에 신청자에게 안내 메일을 보내는 버튼을 만들어줘." (axhub 메일 기능 — [AXHUB.md §5](./AXHUB.md#5-알림--메일))

## 배포 · 확인

- 배포: Claude Code 에서 `/axhub:deploy`
- 배포가 끝나면 앱 주소로 들어가 axhub 로 로그인 → 「새 이벤트」로 이벤트를 하나 만들어 보세요.

## 내 컴퓨터에서 실행 (개발자용)

```bash
npm install
npm run setup          # .env.local 만들기
npm run db:up          # 로컬 Postgres (Docker Desktop 필요)
# .env.local 의 DATABASE_URL 줄 주석(#)을 지워요
npm run dev            # http://localhost:3000
```

로컬 개발(`npm run dev`)에서는 axhub 로그인이 없어서 누구나 담당자로 취급돼요 ("로컬 실행 중"). 실제 로그인·권한은 배포한 뒤 확인하세요.
배포본(production 빌드)에서 axhub 설정(`APPHUB_*`)이 비어 있으면 아무도 담당자로 들이지 않고 "axhub 설정이 비어 있어요" 안내만 보여요.

| 명령 | 하는 일 |
|---|---|
| `npm run check:design` | 디자인 토큰 규칙 검사 (배포 전에 자동으로 돌아요) |
| `npm run check:logic` | CSV 읽기 · 중복 · 정원 판정 규칙 점검 (Node 22.6 이상) |
| `npx tsc --noEmit` · `npm run lint` | 타입 · 코드 규칙 검사 |

| 환경변수 | 용도 |
|---|---|
| `DATABASE_URL` · `DIRECT_DATABASE_URL` | 앱 데이터 DB. 배포하면 axhub 가 자동으로 넣어 줘요 |
| `APPHUB_API_URL` | Hub API origin (`{{API_BASE}}`) — 로그인 |
| `APPHUB_APP_SLUG` | 내 앱 슬러그 (`{{APP_SLUG}}`) |
| `APPHUB_TENANT` | 내 테넌트 슬러그 (`{{TENANT}}`) |

`APPHUB_*` 값은 axhub 로 앱을 만들 때 코드의 `{{...}}` 자리에 미리 채워져요.
