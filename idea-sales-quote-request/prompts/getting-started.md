# 시작용 프롬프트 모음

이 앱은 견적 요청 접수·배정 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 내 요청 화면에서 견적 요청을 하나 등록해 보고
전체 요청 화면에서 담당자를 배정하려면 어디를 누르면 되는지 알려줘.
```

## 2. 배정 알림

```
팀장이 담당자를 배정하면 그 담당자에게 axhub 알림을 보내 줘. 알림을 누르면 내 요청 화면으로 가게 해 줘.
새 요청이 등록되면 앱 관리자에게도 알림을 보내 줘. (AXHUB.md §5 참고)
```

## 3. 견적 금액과 수주 합계

```
견적 발송으로 바꿀 때 견적 금액(원)을 꼭 적게 해 줘.
전체 요청 화면 위에 이번 달 수주 건수와 수주 금액 합계를 보여 줘.
```

## 4. 진행 기록

```
요청마다 메모를 남길 수 있게 하고, 담당자 배정 · 상태 변경 기록을 시간순으로 보여 줘.
메모는 그 요청의 담당자와 팀장만 쓸 수 있게 해 줘.
```

## 5. 담당자도 상태를 바꾸게

```
담당자도 자기에게 배정된 요청의 상태를 견적 발송까지는 바꿀 수 있게 해 줘.
수주 · 실패로 바꾸는 건 지금처럼 팀장만 할 수 있게 해 줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 팀장만 해야 하는 동작이 서버(app/actions.ts)에서도 isLeader 로 막혀 있나?
- 팀장이 아닌 사람이 남의 요청을 볼 수 있는 경로가 있나? (lib/quote-store.ts 의 mine 조건)
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
