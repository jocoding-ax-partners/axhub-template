# 견적 요청 접수

영업팀이 고객에게 받은 견적 요청을 등록하고, 팀장이 요청마다 담당자를 배정하고 진행 상태를 관리하는 앱이에요.
로그인은 axhub 계정으로 하고, 요청 내용은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**영업팀원**
- 받은 견적 요청을 등록해요. 회사명, 고객 담당자, 연락처, 요청 품목, 수량, 희망 납기를 적어요.
- "내 요청" 에서 나에게 배정됐거나 내가 등록한 요청만 봐요. 다른 사람 요청은 보이지 않아요.
- 상태(접수 · 견적 발송 · 수주 · 실패)별로 걸러 보고, 회사명 · 품목 · 고객 이름 · 연락처로 찾아요.
- 납기가 다가오면 D-3 처럼, 지나면 "2일 지남" 으로 표시돼요.

**팀장**
- "전체 요청" 에서 모든 요청을 보고, 요청마다 담당자를 배정하고 상태를 바꿔요.
- 수주 · 실패로 바꿀 땐 한 번 더 물어봐요. 잘못 바꿨다면 다시 다른 상태를 고르면 돼요.
- 상태별 건수를 탭에서 보고, "미배정만" 으로 아직 담당자가 없는 요청만 골라 봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 요청 | `/` | 로그인한 모든 사람. 새 요청 등록 + 내 담당 · 내가 등록한 요청 목록 |
| 전체 요청 | `/admin` | 팀장만. 다른 사람이 열면 "팀장만 볼 수 있어요" 가 보여요 |

## 규칙

- 새 요청은 "접수" 상태로 시작하고, 담당자는 비어 있어요.
- 담당자는 이 앱에 한 번이라도 들어온 사람 중에서 골라요. 목록에 없는 팀원은 앱 주소를 받아 한 번 열어 보면 후보에 올라가요.
- 희망 납기는 오늘 이후 날짜만 등록할 수 있어요. 날짜와 시각은 모두 한국 시간이에요.
- 등록한 요청은 지우지 않아요. 진행되지 않은 요청은 팀장이 "실패" 로 바꿔요.
- 요청마다 누가 언제 등록했고, 마지막으로 누가 언제 바꿨는지 남아요.

## 팀장(관리자)은 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이 팀장이에요. 따로 설정하지 않아도 아래 사람은 자동으로 팀장이에요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 팀장 역할을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 팀장 화면을 쓸 수 있게 해줘. `lib/quote.ts` 의 isLeader 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 팀장이 돼요. 영업팀원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "팀장 역할을 맡을 사람의 axhub 사용자 ID 목록을 전체 요청 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 팀장으로 두고."

영업팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

- `quote_requests` — 견적 요청 한 건이 한 줄이에요. 회사명, 고객 담당자, 연락처, 품목, 수량, 희망 납기, 상태, 담당자,
  등록한 사람과 시각, 마지막으로 바꾼 사람과 시각이 들어가요.
- `members` — 앱에 들어온 사람(axhub 사용자 ID · 이름 · 이메일). 팀장이 담당자를 고르는 목록이에요.

고객 연락처가 들어 있으니 앱 공개 범위는 영업팀으로 좁혀 두세요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 배정은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 견적 요청 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
