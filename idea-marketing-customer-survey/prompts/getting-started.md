# 시작용 프롬프트 모음

이 앱은 고객 설문 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 설문 관리에서 객관식 2개·주관식 1개짜리 설문을 만들고,
응답 링크로 들어가 응답한 뒤 결과 화면에 막대가 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 결과 내려받기

```
설문 결과 화면에 응답 전체를 CSV 로 내려받는 버튼을 추가해줘. 담당자만 받을 수 있게 하고,
엑셀에서 한글이 안 깨지게 UTF-8 BOM 을 붙이고, = + - @ 로 시작하는 답은 수식으로 실행되지 않게 막아줘.
```

## 3. 마감일

```
설문을 만들 때 마감일(날짜)을 정할 수 있게 해줘. 한국 시간으로 그날이 지나면 응답을 받지 않고,
직원 목록에는 "D-3" 처럼 남은 날을 보여줘.
```

## 4. 알림 붙이기

```
새 설문을 만들면 직원들에게 axhub 알림으로 응답 링크를 보내줘. (AXHUB.md §5 참고)
마감 하루 전에는 아직 응답하지 않은 사람에게만 한 번 더 알려줘.
```

## 5. 문항 종류 늘리기

```
객관식에 "여러 개 고르기" 문항과 1~5점 척도 문항을 추가해줘. 결과 화면에는 척도의 평균 점수도 보여줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 담당자만 해야 하는 동작이 서버(app/actions.ts)에서도 isManager 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
