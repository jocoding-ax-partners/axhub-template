# 고객 설문

담당자가 설문을 만들어 링크를 보내면, 직원들이 한 번씩 응답하고, 담당자는 문항별 결과를 막대 차트와 목록으로 보는 앱이에요.
로그인은 axhub 계정으로 하고, 설문과 응답은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 진행 중인 설문 목록에서 아직 응답하지 않은 설문을 먼저 봐요. 제목으로 찾을 수도 있어요.
- 담당자가 보낸 링크(`/s/번호`)로 들어와 응답해요. 객관식은 꼭 하나 골라야 하고, 주관식은 비워 둬도 돼요.
- 설문마다 **한 번만** 응답할 수 있어요. 두 번째로 열면 "응답해 주셔서 고마워요" 만 보여요.

**담당자(관리자)**
- 설문을 만들어요 — 제목, 안내 문구, 문항(객관식 또는 주관식). 객관식 보기는 2~10개, 문항은 30개까지예요. 문항 순서를 위·아래로 바꿀 수 있어요.
- 응답 링크를 복사해 직원들에게 보내요.
- 객관식은 보기별 응답 비율(%)과 인원을 막대 차트로, 주관식은 최근 답 5개를 보고 "모두 보기" 에서 전부 찾아봐요.
- 설문을 마감하거나 다시 열고, 필요 없으면 지워요. 누르기 전에 한 번 더 물어봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 설문 응답 | `/` | 로그인한 모든 사람 |
| (응답 화면) | `/s/번호` | 링크를 받은 모든 사람 |
| 설문 관리 | `/admin` · `/admin/new` · `/admin/surveys/번호` | 관리자만. 다른 사람이 열면 "설문 담당자만 볼 수 있어요" 가 보여요 |

## 설문 규칙

- 한 사람당 한 번 — axhub 사용자 ID 로 구분해요. 동시에 두 번 눌러도 DB 가 한 번만 받아요.
- 결과 화면에는 **누가 응답했는지 보이지 않아요.** (한 번만 받으려고 사용자 ID 는 저장돼요.)
- 만든 뒤에는 문항을 고칠 수 없어요. 이미 받은 응답과 어긋나지 않게 하려는 거예요. 고쳐야 하면 새 설문을 만들어요.
- 마감한 설문은 직원 목록에서 사라지고, 링크로 들어와도 응답할 수 없어요. 다시 열면 아직 응답하지 않은 사람이 응답할 수 있어요.
- 비율은 그 문항에 답한 사람 수 기준이에요. 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

관리자는 모든 설문을 만들고, 결과를 보고, 마감·삭제할 수 있어요. 관리자도 직원처럼 설문에 응답할 수 있어요.

이 앱에서만 설문을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 설문 관리를 할 수 있게 해줘. `lib/survey.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 담당자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "설문 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

| 표 | 한 줄 = | 내용 |
|---|---|---|
| `surveys` | 설문 하나 | 제목, 안내 문구, 상태(진행 중·마감), 만든 사람 이름, 만든·마감한 시각 |
| `survey_questions` | 문항 하나 | 순서, 종류(객관식·주관식), 질문, 객관식 보기 목록 |
| `survey_responses` | 한 사람의 응답 한 번 | 설문, 응답한 사람의 axhub 사용자 ID, 응답 시각 |
| `survey_answers` | 문항 하나의 답 | 고른 보기 번호(객관식) 또는 적은 글(주관식) |

설문을 지우면 문항·응답·답이 함께 지워져요. 결과 비율은 따로 저장하지 않고 볼 때마다 DB 에서 세요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 설문 만들기 · 응답은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 설문 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
