# 시작용 프롬프트 모음

이 앱은 디자인 요청 접수 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 새 요청 화면에서 참고 이미지를 붙여 배너 요청을 하나 올려 보고
요청 관리 화면에서 그 요청을 맡아 결과물을 올리려면 어디를 누르면 되는지 알려줘.
```

## 2. 요청자 검토 받기

```
검토 요청 단계에서 요청자가 결과물을 보고 '수정 요청'(의견 필수) 또는 '완료' 를 직접 누를 수 있게 해줘.
수정 요청을 누르면 작업 중으로 돌아가고, 의견은 요청 상세에 기록으로 남겨줘.
```

## 3. 알림 붙이기

```
새 디자인 요청이 들어오면 앱 관리자(디자이너)에게 axhub 알림을 보내고,
단계가 바뀌거나 결과물이 올라오면 요청자에게 알림을 보내줘. (AXHUB.md §5 참고)
```

## 4. 요청 종류 · 항목 바꾸기

```
요청 종류에 '포스터' 와 '유튜브 썸네일' 을 추가하고, 새 요청 폼에 '사용할 채널' 칸(선택)을 하나 더해줘.
이미 올라온 요청에도 문제없게 DB 에 칸을 추가해줘.
```

## 5. 내 담당만 보기

```
요청 관리 화면에 '내가 맡은 요청만' 보기 버튼을 추가해줘. 검색어 · 단계 탭과 함께 쓸 수 있게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 디자이너만 해야 하는 동작이 서버(app/actions.ts)에서도 isDesigner 와 맡은 사람 확인으로 막혀 있나?
- 파일을 열 때 app/files/[id] 에서 요청자 본인 · 디자이너인지 확인하나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
