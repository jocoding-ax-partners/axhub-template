# 디자인 요청 접수

배너 · 상세페이지 같은 디자인 제작 요청을 받고, 디자이너가 진행 단계와 결과물을 공유하는 앱이에요.
로그인은 axhub 계정으로 하고, 요청 내용은 이 앱 전용 axhub DB 에, 파일은 axhub 파일 저장소에 저장돼요.

## 할 수 있는 일

**요청자 (로그인한 모든 사람)**
- 종류(배너 · 상세페이지 · SNS 이미지 · 기타), 크기, 들어갈 문구, 희망 마감일을 적고 참고 자료 파일을 붙여 요청해요.
- 내 요청 목록에서 진행 단계(접수 · 작업 중 · 검토 요청 · 완료)와 결과물을 봐요. 문구 · 크기로 찾을 수 있어요.
- 아직 아무도 맡지 않은(접수) 요청은 직접 취소할 수 있어요. 누르기 전에 한 번 더 물어봐요.

**디자이너 (앱 관리자)**
- 들어온 요청을 단계별로 보고, 요청자 · 문구 · 디자이너 이름으로 찾아요. 끝나지 않은 요청이 마감 급한 순서로 먼저 보여요.
- 요청을 맡으면 작업 중으로 바뀌어요. 다른 디자이너가 맡은 요청은 확인을 거쳐 이어받을 수 있어요.
- 결과물 파일을 올리고, 검토 요청 · 완료로 단계를 바꿔요. 완료한 요청도 「다시 작업하기」 로 되돌릴 수 있어요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 요청 | `/` | 로그인한 모든 사람 |
| 새 요청 | `/new` | 로그인한 모든 사람 |
| 요청 관리 | `/manage` | 디자이너만. 다른 사람이 열면 "디자이너만 볼 수 있어요" 가 보여요 |
| 요청 상세 | `/requests/번호` | 그 요청을 올린 사람과 디자이너만 |

## 진행 규칙

- 접수 → (디자이너가 맡기) → 작업 중 ⇄ 검토 요청 → 완료. 완료 뒤에도 「다시 작업하기」 로 작업 중으로 돌아갈 수 있어요.
- 단계는 **맡은 디자이너만** 바꿔요. 검토 요청 · 완료는 결과물이 하나 이상 있어야 해요.
- 결과물은 작업 중 · 검토 요청 단계에서만 올리거나 지울 수 있어요. 요청 한 건에 20개까지예요.
- 희망 마감일은 오늘부터 1년 안에서 골라요. 마감이 지난 요청은 목록에 "○일 지남" 으로 보여요.
- 날짜와 시각은 모두 한국 시간이에요.

## 파일

- 받는 형식: JPG · PNG · GIF · WEBP · PDF · AI · PSD · ZIP. 파일 이름이 아니라 **파일 내용**으로 형식을 확인해서, 이름만 바꾼 다른 파일은 받지 않아요.
- 파일 하나 20MB, 한 번에 5개 · 합쳐서 50MB 까지 올려요. 참고 자료는 요청 한 건에 5개까지예요.
- 파일 저장소는 비공개예요. 요청한 사람과 디자이너만 열 수 있고, 열 때마다 5분 동안만 쓸 수 있는 주소가 만들어져요.
  이미지 · PDF 는 새 탭에서 열리고, PSD · ZIP 은 원래 이름으로 내려받아져요.

## 디자이너(관리자)는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 디자이너예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 디자이너 역할을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 디자이너로 요청 관리를 할 수 있게 해줘. `lib/design.ts` 의 isDesigner 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 디자이너가 돼요. 요청자도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "디자이너로 일할 사람의 axhub 사용자 ID 목록을 요청 관리 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 디자이너로 두고."

요청자가 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

- `design_requests` 표 — 요청 한 건이 한 줄이에요. 요청자(axhub 사용자 ID · 이름 · 이메일), 종류, 크기, 문구, 희망 마감일, 단계, 담당 디자이너, 만든 · 바뀐 시각.
- `design_files` 표 — 파일 한 개가 한 줄이에요. 어느 요청의 참고 자료인지 결과물인지, 파일 이름 · 형식 · 크기, 올린 사람과 시각.
  파일 자체는 axhub 파일 저장소에 있고 표에는 저장소 열쇠만 있어요. 요청을 취소하거나 결과물을 지우면 저장소의 파일도 같이 지워져요.

표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인과 파일 저장소가 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 요청 · 파일 올리기는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 파일 저장 · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 요청 · 파일 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
