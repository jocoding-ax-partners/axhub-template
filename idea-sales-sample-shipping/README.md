# 샘플·자료 발송 기록

고객사에 보낸 샘플과 자료를 **누구에게 · 무엇을 · 언제** 보냈는지 기록하고, 후속 연락할 날을 놓치지 않게 알려 주는 팀용 앱이에요.
로그인은 axhub 계정으로 하고, 기록은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

- 발송 건을 기록해요 — 받는 고객사 · 받는 담당자 · 보낸 것 · 보낸 날 · 후속 연락 예정일 · 메모.
  고객사 칸은 전에 적은 이름을 자동완성으로 보여 줘서, 같은 고객사를 조금씩 다르게 적지 않게 도와줘요.
- 홈에서 **후속 연락 예정일이 오늘이거나 지난 건**을 오래 밀린 것부터 먼저 보여 줘요. 연락했으면 **완료**를 눌러요. 잘못 눌렀으면 "완료 취소" 로 되돌려요.
- 고객사 이름으로 찾고, 고객사를 누르면 그 고객사에 보낸 **발송 이력**을 최근 것부터 봐요.
- 발송 기록 전체를 고객사 · 담당자 · 보낸 것 · 메모로 찾아요. "팀 전체 / 내가 기록한 건" 탭으로 나눠 봐요.

## 화면

| 메뉴 | 주소 | 하는 일 |
|---|---|---|
| 오늘 할 연락 (홈) | `/` | 요약 숫자(연락할 때가 된 건 · 앞으로 연락할 건 · 이번 달 보낸 건), 연락할 때가 된 건 목록, 최근 발송 5건 |
| 발송 기록 | `/shipments` | 전체 발송 기록, 검색, 30건씩 페이지 나눔. "발송 기록하기" 로 새로 기록(`/shipments/new`) |
| 발송 한 건 | `/shipments/번호` | 내용 보기. 기록한 사람과 관리자는 여기서 고치고 지워요 |
| 고객사 | `/customers` | 발송한 적 있는 고객사를 최근 보낸 순으로. 이름 검색, 연락할 때가 된 건 수 표시 |
| 고객사 발송 이력 | `/customers/history?name=고객사` | 그 고객사에 보낸 기록 전부와 요약. "이 고객사에 발송 기록" 버튼 |

## 규칙

- 고객사는 이름으로 묶어요. 앞뒤 공백과 영문 대소문자는 가리지 않아요 (`ACME Korea` 와 `acme korea` 는 같은 고객사).
- 보낸 날은 오늘이나 그 전 날짜만 적을 수 있어요. 후속 연락 예정일은 선택이고, 보낸 날보다 앞설 수 없고, 오늘부터 1년 안이에요.
- 후속 연락 예정일을 바꾸면 "연락 완료" 표시가 풀려요 — 새로 잡은 연락은 아직 안 한 거라서요.
- 지우기는 한 번 더 물어보고, 지운 기록은 되돌릴 수 없어요.
- 날짜와 "오늘" 은 모두 한국 시간이에요.

## 누가 무엇을 할 수 있나요

| | 로그인한 누구나 | 기록한 사람 | 관리자 |
|---|---|---|---|
| 모든 발송 기록 · 고객사 이력 보기, 새로 기록 | ✓ | ✓ | ✓ |
| 고치기 · 지우기 · 연락 완료 표시 | | 자기 기록만 | 모든 기록 |

### 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 관리자 일을 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 모든 발송 기록을 고치고 지울 수 있게 해줘. `lib/shipment.ts` 의 canManage 와 `lib/shipment-store.ts` 의 manageable 두 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 팀원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "관리자 일을 맡을 사람의 axhub 사용자 ID 목록을 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`shipments` 표 하나에 발송 한 건이 한 줄로 저장돼요.
받는 고객사 · 담당자 · 보낸 것 · 보낸 날 · 후속 연락 예정일 · 메모, 연락 완료한 시각과 사람, 기록한 사람(axhub 사용자 ID · 이름)과 시각이에요.
고객사 목록은 따로 저장하지 않고 발송 기록을 이름으로 묶어서 매번 만들어요.
표는 앱이 처음 쓰일 때 자동으로 만들어지고, 샘플 데이터는 넣지 않아요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 기록 · 완료 표시는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 발송 기록 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
