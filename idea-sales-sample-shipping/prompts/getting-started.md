# 시작용 프롬프트 모음

이 앱은 샘플·자료 발송 기록 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 발송을 하나 기록하고 후속 연락 예정일을 오늘로 잡아서
홈 "연락할 때가 된 건" 에 보이는지, 완료를 누르면 빠지는지 어디서 확인하면 되는지 알려줘.
```

## 2. 후속 연락 알림

```
후속 연락 예정일 아침 9시(한국 시간)에 그 건을 기록한 사람에게 axhub 알림을 보내줘.
알림을 누르면 그 발송 기록 화면으로 가게 해줘. (AXHUB.md §5 참고)
```

## 3. 기록 칸 늘리기

```
발송 기록에 택배사와 운송장 번호 칸을 추가해줘. 둘 다 선택 입력이고,
목록에는 운송장 번호를 작게 보여줘. 이미 저장된 기록도 깨지지 않게 해줘.
```

## 4. 연락 결과 남기기

```
완료를 누를 때 고객 반응(좋음 · 보통 · 반응 없음)과 한 줄 메모를 남길 수 있게 해줘.
고객사 발송 이력에서 반응도 같이 보이게 해줘.
```

## 5. 내려받기

```
발송 기록 화면에서 기간을 골라 CSV 로 내려받게 해줘. 엑셀에서 한글이 깨지지 않게(UTF-8 BOM),
= + - @ 로 시작하는 칸은 수식으로 실행되지 않게 막아줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 고치기 · 지우기 · 완료 표시가 서버(lib/shipment-store.ts 의 manageable)에서도 기록한 사람 · 관리자로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
