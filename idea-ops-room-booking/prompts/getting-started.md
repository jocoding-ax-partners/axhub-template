# 시작용 프롬프트 모음

이 앱(회의실 예약)을 고칠 때 Claude Code 에 그대로 붙여 넣거나 조금 바꿔서 써요.
구조와 규칙은 CLAUDE.md 의 "이 앱: 회의실 예약" 에 있어요.

## 1. 시간표 범위 바꾸기

```
시간표를 07:00~22:00 으로 넓혀줘. lib/booking.ts 의 DAY_START / DAY_END 를 바꾸고,
lib/db.ts 의 CHECK 제약과 맞는지도 확인해줘. npm run check:logic 이 통과해야 해.
```

## 2. 회의실 고치기·삭제하기 (관리자)

```
회의실 관리 화면에서 관리자가 회의실 이름·수용 인원을 고치고 삭제할 수 있게 해줘.
서버 액션에서 me().is_admin 을 다시 확인하고, 삭제는 확인창을 띄워줘
(삭제하면 그 회의실 예약도 함께 지워진다고 알려줘).
```

## 3. 회의실 정보 늘리기

```
회의실에 층(예: 3층)과 장비(모니터, 화상회의 장비) 항목을 추가해줘.
ensureSchema() 에 ALTER TABLE rooms ADD COLUMN IF NOT EXISTS 로 넣고,
등록 양식과 시간표 머리글에 보여줘.
```

## 4. 관리자 취소 권한

```
관리자는 시간표에서 다른 사람 예약도 취소할 수 있게 해줘.
일반 직원은 지금처럼 본인 예약만 취소돼야 해. 취소 전에 확인창을 띄워줘.
```

## 5. 예약 알림

```
예약하거나 취소하면 예약한 사람에게 메일로 알려줘. AXHUB.md 의 알림·메일 방법을 써줘.
```

## 6. 배포 전 점검

```
배포 전에 점검해줘: npm run lint, npm run build, npm run check:logic, npm run check:design 이
모두 통과하는지 보고, 그다음 axhub 에 배포하고 성공했는지 확인해줘.
```
