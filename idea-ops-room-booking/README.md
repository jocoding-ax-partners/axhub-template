# 회의실 예약

회사 회의실을 30분 단위로 예약하는 앱이에요. 로그인은 axhub 로그인을 쓰고, 데이터는 axhub 가 이 앱에 만들어 준 전용 데이터베이스에 저장돼요.

- 관리자가 회의실(이름, 수용 인원)을 등록해요.
- 직원은 날짜를 고르고 회의실별 시간표에서 빈 칸을 눌러 예약해요(제목, 시작·종료 시각).
- 겹치는 예약은 받지 않아요. 두 사람이 같은 칸을 동시에 눌러도 한 명만 예약돼요.
- 내 예약 목록에서 예약을 취소할 수 있어요.

> axhub 기능(파일 저장 · 알림 · 공개 범위 · 도메인 · 로그 · 되돌리기 등)을 켜는 법은 [AXHUB.md](./AXHUB.md) 에 모아 뒀어요.

## 화면

| 메뉴 | 누가 | 하는 일 |
|------|------|---------|
| **예약하기** (`/`) | 모두 | 날짜를 고르면(이전·다음·오늘·직접 고르기) 08:00~20:00 시간표가 보여요. 빈 칸을 누르면 예약 양식이 열려요. 지난 시간은 회색으로 막혀 있어요. |
| **내 예약** (`/my`) | 로그인한 사람 | 오늘부터 잡혀 있는 내 예약이에요. 「예약 취소」를 누르면 한 번 더 물어본 뒤 취소해요. |
| **회의실 관리** (`/rooms`) | 목록은 모두, 등록은 관리자 | 회의실 목록을 보고, 관리자는 새 회의실을 등록해요. |

시간표는 한국 시간(KST) 기준이에요. 휴대폰처럼 좁은 화면에서는 시간표를 옆으로 밀어서 다른 회의실을 봐요.

## 누가 관리자인가요

axhub 가 알려 주는 "이 앱의 관리자"를 그대로 써요. 따로 관리자 명단을 두지 않아요.

- **앱을 만든 사람(소유자)** 과 **워크스페이스 관리자**가 관리자예요.
- 이 앱의 회의실 등록만 다른 사람에게 맡기려고 그 사람을 워크스페이스 관리자로 올릴 필요는 없어요(그러면 회사 전체 권한이 생겨요). 대신 그 사람을 이 앱에 초대하고(`axhub access invite --app <슬러그> --user <사용자ID> --execute`, 자세한 건 [AXHUB.md](./AXHUB.md) §7), 초대받은 사람의 앱 역할(`app_role`)도 관리자로 쳐 주게 Claude 에게 부탁하세요.
  > "`me().app_role` 이 `app_member`(이 앱에 초대된 사람)면 회의실 등록을 할 수 있게 해줘. 화면의 등록 양식과 서버 액션 둘 다 같은 규칙으로 바꿔줘"

  일부공개 앱에서는 초대한 사람이 모두 `app_member` 가 되니, 초대한 사람 모두가 등록할 수 있게 된다는 점을 알고 쓰세요.
- 관리자가 아닌 사람이 등록을 시도해도 서버에서 다시 확인해 막아요.

예약과 취소는 로그인한 사람 누구나 할 수 있고, 취소는 **본인 예약만** 돼요.

## 저장하는 데이터

| 표 | 내용 |
|----|------|
| `rooms` (회의실) | 이름(1~50자, 중복 불가), 수용 인원(1~1000명) |
| `bookings` (예약) | 회의실, 날짜, 시작·종료 시각(30분 단위), 제목(1~100자), 예약한 사람(axhub 사용자 ID와 이름) |

표는 앱이 처음 열릴 때 자동으로 만들어져요. 따로 할 일이 없고, 처음에는 회의실이 비어 있어요 — 관리자가 「회의실 관리」에서 첫 회의실을 등록하면 시작돼요.

겹침 방지는 데이터베이스 규칙(`bookings_no_overlap`)이 맡아요. 화면이나 코드를 바꿔도 같은 회의실·같은 날에 시간이 겹치는 예약은 저장되지 않아요.

## Claude 에게 이렇게 부탁해 고쳐 보세요

axhub 플러그인이 설치된 Claude Code 를 이 폴더에서 열고 말로 요청하면 돼요.

- "시간표를 오전 7시부터 밤 10시까지 보이게 바꿔줘"
- "회의실 관리에서 회의실 이름·인원을 고치고 삭제할 수 있게 해줘. 삭제 전에 꼭 확인을 받아줘"
- "회의실에 층과 장비(모니터, 화상회의) 항목을 추가하고 시간표 머리글에 보여줘"
- "관리자는 다른 사람 예약도 취소할 수 있게 해줘"
- "예약하면 예약한 사람에게 메일로 알려줘"

다 고쳤으면 "axhub 에 배포하고 성공했는지 확인해줘" 라고 하면 돼요.

## 내 컴퓨터에서 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.example → .env.local (로컬 DB 주소가 들어 있어요)
npm run db:up     # Docker 로 로컬 PostgreSQL 기동
npm run dev       # http://localhost:3000
```

로컬에는 axhub 로그인 문이 없어서 방문자가 "로그인 안 함"으로 보여요. 시간표·회의실 목록은 볼 수 있지만 예약·등록은 배포한 앱에서 해 보세요.

| 명령 | 하는 일 |
|------|---------|
| `npm run check:logic` | 예약 시간 규칙(날짜·30분 단위·지난 시간·KST) 점검 (Node 22 이상) |
| `npm run check:design` | 디자인 토큰 규칙 검사 (배포 전에도 자동으로 돌아요) |
| `npm run lint` / `npm run build` | 코드 검사 / 빌드 |

코드 구조와 규칙은 [CLAUDE.md](./CLAUDE.md) · [AGENTS.md](./AGENTS.md) 에 있어요.
