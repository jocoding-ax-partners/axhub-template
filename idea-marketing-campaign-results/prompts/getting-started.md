# 시작용 프롬프트 모음

이 앱은 캠페인 성과 기록 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 캠페인을 하나 등록하고 날짜별 성과를 이틀치 적어 보면
캠페인 비교 표와 상세 화면 차트에서 어디를 보면 되는지 알려줘.
```

## 2. 매출과 ROAS 더하기

```
날짜별 기록에 전환 매출(원)을 적는 칸을 더하고, 캠페인 비교 표와 상세 화면에
ROAS(매출 ÷ 비용 × 100%)를 보여줘. 이미 저장된 기록은 매출 0 으로 두면 돼.
```

## 3. 채널별로 모아 보기

```
채널별 합계 화면을 추가해줘. 채널마다 캠페인 수, 비용, 클릭률, 전환당 비용을 보여 주고
사이드바 메뉴에도 넣어줘.
```

## 4. CSV 로 내려받기

```
캠페인 비교 표를 CSV 로 내려받는 버튼을 만들어줘. 엑셀에서 한글이 깨지지 않게 하고,
지금 검색어와 정렬을 그대로 따라가게 해줘.
```

## 5. 날짜별 광고비

```
지금은 캠페인 비용을 한 번만 적어. 날짜별로 그날 쓴 광고비를 적을 수 있게 바꾸고,
캠페인 비용은 날짜별 광고비의 합으로 계산해줘. 상세 차트에 날짜별 전환당 비용도 그려줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 고치기·삭제·날짜별 입력이 서버(lib/campaign-store.ts)에서도 canEdit 으로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
