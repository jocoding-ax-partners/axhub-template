# 캠페인 성과 기록

캠페인별 비용·노출·클릭·전환을 기록하고, 클릭률과 전환당 비용으로 효율을 비교하는 앱이에요.
로그인은 axhub 계정으로 하고, 기록은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

- 캠페인(이름 · 채널 · 기간 · 비용)을 등록해요. 채널은 목록(네이버 검색광고 · 구글 애즈 · 메타 …)에서 고르거나 직접 적어요.
- 캠페인 상세에서 날짜별 노출 · 클릭 · 전환 수를 적어요. 이미 적은 날짜를 다시 저장하면 새 숫자로 바뀌고, 목록의 "고치기" 로 그날 숫자를 불러올 수도 있어요.
- 캠페인 비교 화면에서 캠페인마다 총 비용 · 노출 · 클릭 · 전환, **클릭률**과 **전환당 비용**을 한 표로 봐요.
  최근 시작 순 · 전환당 비용 낮은 순 · 클릭률 높은 순으로 정렬하고, 이름이나 채널로 찾을 수 있어요. 위쪽에는 전체 합계가 보여요.
- 캠페인 상세에서 날짜별 클릭 · 전환 추이를 선 차트로 봐요.
- 캠페인 정보를 고치거나 지워요. 지우기 전에 한 번 더 물어봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 캠페인 비교 | `/` | 로그인한 모든 사람 |
| 새 캠페인 | `/campaigns/new` | 로그인한 모든 사람 |
| 캠페인 상세 | `/campaigns/번호` | 로그인한 모든 사람이 봐요. 날짜별 입력 · 고치기 · 삭제는 등록한 사람과 관리자만 |
| 캠페인 고치기 | `/campaigns/번호/edit` | 등록한 사람과 관리자만 |

## 계산 규칙

- **클릭률** = 클릭 ÷ 노출 × 100 (소수 둘째 자리까지). 노출이 0 이면 `–` 로 보여요.
- **전환당 비용** = 캠페인 비용 ÷ 전환 수. 전환이 0 이면 `–` 로 보여요. 비용은 캠페인 기간 전체에 쓴 금액 한 번만 적어요.
- 총 노출 · 클릭 · 전환은 날짜별 기록을 더한 값이에요. 합계는 따로 저장하지 않고 볼 때마다 계산해요.
- 날짜별 기록은 캠페인 기간 안의 날짜만 적을 수 있어요. 클릭 수는 노출 수보다 많을 수 없어요 (전환은 클릭보다 많아도 돼요 — 광고를 보고 나중에 전환한 경우).
- 캠페인 기간은 최대 366일이에요. 기간을 줄일 때 바뀐 기간 밖에 기록이 있으면 먼저 그 기록을 지워야 해요.
- 캠페인을 지우면 그 캠페인의 날짜별 기록도 함께 지워져요. 되돌릴 수 없어요.
- 날짜는 모두 한국 시간이에요.

## 관리자는 누구인가요

로그인한 사람은 누구나 캠페인을 등록하고, 모든 캠페인의 성과를 볼 수 있어요.
캠페인을 고치거나 지우고 날짜별 숫자를 적는 건 **그 캠페인을 등록한 사람**과 **관리자**만 할 수 있어요.

관리자는 axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 모든 캠페인을 관리할 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 모든 캠페인을 고칠 수 있게 해줘. `lib/campaign.ts` 의 canEdit 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 팀원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "모든 캠페인을 관리할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

표 두 개에 저장돼요.

- `campaigns` — 캠페인 한 개가 한 줄. 이름, 채널, 시작일 · 종료일, 비용(원), 등록한 사람(axhub 사용자 ID · 이름), 만든 · 고친 시각.
- `campaign_daily` — 캠페인 · 날짜마다 한 줄. 노출 · 클릭 · 전환 수.

클릭률 · 전환당 비용 같은 지표는 저장하지 않고 매번 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

- "캠페인 상세 차트에 노출 추이도 같이 그려줘"

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 입력은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 캠페인 규칙 (입력 검사 · 지표 계산) | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
