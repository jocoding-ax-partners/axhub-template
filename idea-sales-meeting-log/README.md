# 고객 미팅 기록

고객사를 등록하고, 고객사마다 미팅 기록을 남기는 팀용 앱이에요.
미팅 때 정한 **다음 연락일**이 오늘이거나 지났으면 홈 맨 위에 보여 줘서, 연락할 곳을 놓치지 않게 도와요.

- 로그인: axhub 로그인을 그대로 써요. 로그인한 사람만 들어올 수 있어요.
- 저장: 데이터는 이 앱 전용 axhub 데이터베이스에 저장돼요. 처음 열면 필요한 표를 앱이 알아서 만들어요.

## 화면

| 화면 | 주소 | 하는 일 |
|---|---|---|
| 고객사 (홈) | `/` | **연락할 때가 된 고객사**(다음 연락일이 오늘이거나 지난 곳)를 오래 밀린 순으로 먼저, 그 아래 **나머지 고객사**를 보여 줘요. 고객사 이름으로 찾기, **내 담당만** 보기, 30곳씩 페이지 나눔. |
| 고객사 등록 | `/companies/new` | 회사명(필수) · 담당자 · 연락처를 등록해요. 등록한 사람이 그 고객사의 담당이 돼요. |
| 고객사 상세 | `/companies/번호` | 고객사 정보, 미팅 기록 남기기(날짜 · 참석자 · 내용 · 다음 할 일 · 다음 연락일), 지난 미팅 목록. 연락처가 전화번호·이메일이면 바로 걸거나 메일을 쓸 수 있어요. |

**다음 연락일**은 그 고객사의 가장 최근 미팅(미팅 날짜 기준)에 적은 다음 연락일이에요. "오늘"은 늘 한국 시간 기준이에요.

## 누가 무엇을 할 수 있나요

| | 로그인한 누구나 | 고객사 담당(등록한 사람) | 앱 관리자 |
|---|---|---|---|
| 고객사·미팅 기록 보기, 고객사 등록 | ✓ | ✓ | ✓ |
| 미팅 기록 남기기 | ✓ | ✓ | ✓ |
| 내가 남긴 미팅 기록 지우기 | ✓ | ✓ | ✓ |
| 고객사 정보 고치기 · 고객사 지우기 · 그 고객사의 모든 기록 지우기 | | ✓ | ✓ |

- **앱 관리자**는 따로 지정하지 않아도 정해져요: 이 앱의 소유자(만든 사람)와 워크스페이스 관리자는 자동으로 관리자예요. 관리자가 아닌 팀원은 담당 고객사만 고칠 수 있어요.
- 이 앱에서만 관리자 일을 맡길 사람이 있으면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요). 대신 앱 초대(`axhub access invite`)로 이 앱의 역할을 주고, Claude 에게 그 역할을 관리자로 쳐 달라고 하면 돼요:
  > "초대한 사람이 로그인했을 때 `me().app_role` 값이 무엇인지 확인해서, 그 역할을 가진 사람도 이 앱의 관리자로 쳐줘. `lib/user.ts` 의 admin 판단만 바꾸면 돼."
- 권한은 화면에서 버튼을 숨기는 것뿐 아니라 저장할 때 서버에서도 다시 확인해요.
- 지우기는 항상 한 번 더 물어보고, 고객사를 지우면 그 미팅 기록도 함께 지워져요 (되돌릴 수 없어요).

## 저장하는 데이터

| 표 | 내용 |
|---|---|
| `companies` (고객사) | 회사명, 고객사 담당자, 연락처, 담당(axhub 사용자 ID와 이름), 등록 시각 |
| `meetings` (미팅 기록) | 고객사, 미팅 날짜, 참석자, 내용, 다음 할 일, 다음 연락일, 기록한 사람, 기록 시각 |

샘플 데이터는 넣지 않아요. 처음에는 빈 화면에서 "첫 고객사 등록하기"로 시작해요.

## Claude 에게 이렇게 고쳐 달라고 해 보세요

이 폴더에서 Claude Code 를 열고 말로 요청하면 돼요.

- "고객사에 업종이랑 주소 칸을 추가해줘. 목록 카드에도 업종을 보여줘."
- "관리자가 고객사 담당을 다른 사람으로 바꿀 수 있게 해줘."
- "미팅 기록도 고칠 수 있게 수정 버튼을 만들어줘."
- "다음 연락일이 사흘 안에 다가오는 고객사도 홈에 따로 모아 보여줘."
- "다음 연락일 아침에 담당자에게 axhub 알림을 보내줘."

## 내 컴퓨터에서 실행하기 (선택)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres 켜기 (Docker Desktop 필요) → .env.local 의 DATABASE_URL 주석 해제
npm run dev       # http://localhost:3000
```

로컬에는 axhub 로그인이 없어서 "로컬 사용자"로 들어가요. 배포는 Claude Code 에서 `axhub 에 배포해줘` 라고 말하면 돼요.
