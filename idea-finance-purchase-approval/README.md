# 구매 요청·결재

직원이 구매할 품목과 금액을 올리고, 관리자가 승인하거나 반려하는 앱이에요.
로그인은 axhub 계정으로 하고, 요청 내용은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 품목, 수량, 단가, 구매 사유를 적어 구매 요청을 올려요. 총액(수량 × 단가)은 입력하는 대로 자동 계산돼요.
- 총액이 100만 원 이상이면 "고액" 표시가 붙어요.
- 내 요청 목록에서 상태(대기 · 승인 · 반려)와 반려 사유를 봐요. 상태별로 나눠 보거나 품목으로 찾을 수 있어요.

**관리자**
- 결재함에서 대기 중인 요청을 먼저 올라온 순서로 보고, 승인하거나 사유를 적어 반려해요. 누르기 전에 한 번 더 물어봐요.
- 대기 건수 · 그중 고액 건수 · 대기 금액 합계를 한눈에 봐요. "고액만 보기" 로 큰 금액부터 챙길 수 있어요.
- 처리 완료 탭에서 지난 결재 기록(처리한 사람 · 시각 · 반려 사유)을 찾아봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 구매 요청 | `/` | 로그인한 모든 사람 |
| 결재함 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |

## 결재 규칙

- 총액 = 수량 × 단가. 저장할 때 DB 가 다시 계산해서, 화면과 다른 값이 저장될 일이 없어요.
- 수량은 1 ~ 10,000개, 단가는 1원 ~ 10억 원 사이의 정수로 적어요. 단가는 쉼표를 넣어 적어도 돼요.
- 총액이 **100만 원 이상**이면 고액이에요 (딱 100만 원도 고액).
- 반려할 때는 사유를 꼭 적어요. 요청자는 내 요청 목록에서 반려 사유를 봐요.
- 한 번 승인하거나 반려하면 되돌릴 수 없어요. 관리자 두 명이 동시에 눌러도 한 번만 처리돼요.
- 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

관리자도 **본인 요청은 스스로 승인할 수 없어요.** 다른 관리자가 처리해요.

이 앱에서만 결재를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 결재함을 쓸 수 있게 해줘. `lib/purchase.ts` 의 isApprover 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "결재함을 쓸 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`purchase_requests` 표 하나에 요청 한 건이 한 줄로 저장돼요.
요청자(axhub 사용자 ID · 이름 · 이메일), 품목, 수량, 단가, 총액, 구매 사유, 상태, 반려 사유, 처리한 사람과 시각이에요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 요청 · 결재는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 구매 요청 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
