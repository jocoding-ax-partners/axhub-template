# 시작용 프롬프트 모음

이 앱은 구매 요청·결재 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 내 구매 요청 화면에서 요청을 하나 올려 보고
결재함에 그 요청이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 고액 기준 바꾸기

```
고액 기준을 100만 원 말고 300만 원으로 바꿔줘. 화면 안내 문구와 README 도 같이 고쳐줘.
```

## 3. 금액 구간별 결재 단계

```
총액 500만 원 이상은 관리자 두 명이 각각 승인해야 최종 승인되게 해줘.
첫 승인 뒤에는 "1차 승인" 상태로 보이게 하고, 같은 사람이 두 번 승인할 수는 없게 해줘.
```

## 4. 알림 붙이기

```
구매 요청이 들어오면 앱 관리자에게 axhub 알림을 보내고,
승인·반려되면 요청한 직원에게 결과와 반려 사유를 알림으로 보내줘. (AXHUB.md §5 참고)
```

## 5. 요청 취소

```
대기 중인 내 요청은 직원이 직접 취소할 수 있게 해줘. 누르기 전에 한 번 더 물어봐 줘.
이미 승인되거나 반려된 요청은 취소할 수 없게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isApprover 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
