# 시작용 프롬프트 모음

이 앱은 휴가 신청·승인 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 내 휴가 화면에서 반차를 하나 신청해 보고
승인 관리 화면에 그 신청이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 연차 규칙 바꾸기

```
한 해 연차를 15일 말고 직원마다 다르게 정할 수 있게 해줘.
관리자 화면 "직원별 연차" 에서 사람마다 연차 일수를 고칠 수 있게 하고, 기본값은 15일로 해줘.
```

## 3. 알림 붙이기

```
휴가 신청이 들어오면 앱 관리자에게 axhub 알림을 보내고,
승인·반려되면 신청한 직원에게 결과와 반려 사유를 알림으로 보내줘. (AXHUB.md §5 참고)
```

## 4. 신청 취소

```
대기 중인 내 신청은 직원이 직접 취소할 수 있게 해줘. 누르기 전에 한 번 더 물어봐 줘.
이미 승인되거나 반려된 신청은 취소할 수 없게 해줘.
```

## 5. 공휴일 빼기

```
연차·병가 일수를 셀 때 한국 공휴일은 빼 줘. 공휴일 목록은 관리자가 화면에서 추가할 수 있게 해줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isApprover 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
