# 시작용 프롬프트 모음

이 앱은 택배·우편 수령 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 안내데스크 화면에서 내 이메일로 택배를 하나 등록해 보고
내 택배 화면에 그 택배가 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 도착 알림 보내기

```
택배를 등록하면 받는 사람에게 axhub 알림을 보내줘. 보낸 곳과 보관 위치를 알림에 넣고,
누르면 내 택배 화면으로 오게 해줘. (AXHUB.md §5 참고)
```

## 3. 오래된 택배 다시 알리기

```
3일 넘게 안 찾아간 택배는 매일 아침 9시(한국 시간)에 받는 사람에게 다시 알려줘.
안내데스크 화면에는 "다시 알림 보내기" 버튼도 만들어줘.
```

## 4. 받는 사람 고르기 쉽게

```
등록할 때 받는 사람 이메일을 다 치지 않아도 되게 해줘.
한 번이라도 이 앱에 로그인한 직원을 기억해 두고, 이름 두 글자를 치면 후보가 나오게 해줘.
```

## 5. 잘못 누른 수령 되돌리기

```
담당자가 수령 완료 탭에서 잘못 처리된 수령을 되돌릴 수 있게 해줘. 누르기 전에 한 번 더 물어봐 줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 담당자만 해야 하는 동작이 서버(app/actions.ts)에서도 isDesk 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
