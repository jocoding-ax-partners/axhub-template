# 택배·우편 수령

안내데스크 담당자가 도착한 택배·우편을 등록하면, 받는 사람이 로그인해서 확인하고 가져간 뒤 "수령" 을 누르는 앱이에요.
로그인은 axhub 계정으로 하고, 택배 기록은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원 (받는 사람)**
- 로그인하면 나에게 온 미수령 택배가 맨 위에 보여요. 보낸 곳 · 보관 위치 · 메모 · 도착 시각을 봐요.
- 가져간 뒤 "수령" 을 누르면 목록에서 빠져요. 누르기 전에 한 번 더 물어봐요.
- 받은 기록에서 지난 택배를 30개씩 넘겨 봐요.

**안내데스크 담당자**
- 도착한 택배를 등록해요: 받는 사람 이메일(필수) · 이름(선택) · 종류(택배 · 우편) · 보낸 곳 · 보관 위치 · 메모(선택).
- 미수령 택배를 도착일 순(오래된 것부터)으로 보고, 받는 사람 · 보낸 곳 · 보관 위치로 찾아요. 3일 넘게 보관 중인 택배는 따로 표시돼요.
- 데스크에서 직접 건넸다면 "대신 수령 처리", 잘못 등록했다면 "등록 취소" 를 눌러요.
- 수령 완료 탭에서 누가 언제 받아 갔는지 봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 내 택배 | `/` | 로그인한 모든 사람 |
| 안내데스크 | `/desk` | 담당자만. 다른 사람이 열면 "담당자만 볼 수 있어요" 가 보여요 |

## 규칙

- 받는 사람은 **axhub 로그인 이메일**로 찾아요. 등록할 때 이메일을 틀리게 적으면 그 사람 화면에 안 보여요 (대소문자는 상관없어요).
- 도착 시각은 등록한 시각이에요.
- 수령은 받는 사람 본인이나 담당자만 할 수 있어요. 다른 사람의 택배는 화면에 보이지도 않아요.
- 한 번 수령 처리하면 되돌릴 수 없어요. 등록 취소는 아직 안 받아 간 택배만 돼요.
- 날짜와 시각은 모두 한국 시간이에요.

## 담당자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 담당자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

안내데스크 직원처럼 이 앱에서만 담당자를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 안내데스크 화면을 쓸 수 있게 해줘. `lib/parcel.ts` 의 isDesk 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 담당자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "안내데스크 담당자의 axhub 사용자 ID 목록을 담당자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 담당자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`parcels` 표 하나에 택배 한 건이 한 줄로 저장돼요.
종류, 받는 사람(이메일 · 이름), 보낸 곳, 보관 위치, 메모, 도착 시각, 등록한 담당자, 수령 시각과 수령 처리한 사람이에요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 등록 · 수령은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 택배 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
