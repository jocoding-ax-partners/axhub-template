# 월간 실적 집계

영업팀원이 계약 건(계약일 · 고객사 · 금액)을 넣으면, 달마다 담당자별 계약 건수와 금액 합계, 팀 전체 합계를 보여 주는 앱이에요.
최근 6개월 팀 합계는 막대 차트로 보여요. 로그인은 axhub 계정으로 하고, 계약은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**영업팀원 (로그인한 모든 사람)**
- 계약일 · 고객사 · 금액을 넣어요. 담당자는 넣은 사람으로 저장돼요.
- 달을 골라 담당자별 계약 건수 · 금액 · 비중과 팀 전체 합계를 봐요. 지난달보다 얼마나 늘었는지도 보여요.
- 고른 달까지 최근 6개월 팀 합계를 막대 차트로 봐요. 막대를 누르면 그 달로 가요.
- 계약 목록을 달별로 보고, 고객사나 담당자 이름으로 찾아요.
- 내가 넣은 계약은 지울 수 있어요. 누르기 전에 한 번 더 물어봐요.

**관리자**
- 위의 일을 모두 하고, 다른 사람이 넣은 계약도 지울 수 있어요 (잘못 들어간 계약 정리용).

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 월간 실적 | `/` (`/?month=2026-10`) | 로그인한 모든 사람 |
| 계약 입력 | `/contracts` | 로그인한 모든 사람. 지우기 버튼은 넣은 본인과 관리자에게만 보여요 |

## 집계 규칙

- 계약은 **계약일**이 속한 달에 들어가요. 넣은 날짜가 아니에요.
- 계약일은 오늘(한국 시간)이나 그 전 날짜만 넣을 수 있어요. 금액은 1원 이상 1조 원 미만의 정수예요.
- 부가세를 넣을지 말지는 앱이 정하지 않아요. 팀에서 하나로 정해 같은 기준으로 넣어 주세요.
- 담당자별 표는 그 달 금액이 큰 순서예요. 담당자 이름은 그 달 가장 최근에 넣은 계약 때 이름을 써요.
- 잘못 넣은 계약은 지우고 다시 넣어요. 지우면 합계에서도 바로 빠지고 되돌릴 수 없어요.
- 날짜와 "이번 달" 은 모두 한국 시간 기준이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 관리를 맡길 사람(예: 영업팀장)이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 관리자처럼 다른 사람 계약을 지울 수 있게 해줘. `lib/sales.ts` 의 isManager · canDelete 만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 영업팀원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "관리자로 둘 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

팀원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

`contracts` 표 하나에 계약 한 건이 한 줄로 저장돼요.
담당자(axhub 사용자 ID · 이름 · 이메일), 계약일, 고객사, 금액, 넣은 시각이에요.
월별 · 담당자별 합계는 따로 저장하지 않고 이 표를 매번 더해서 계산해요.
표는 앱이 처음 쓰일 때 자동으로 만들어져요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 입력 · 집계는 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 실적 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
