# 시작용 프롬프트 모음

이 앱은 월간 영업 실적 집계 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 계약 입력 화면에서 계약을 하나 넣어 보고
월간 실적 화면의 담당자별 표와 6개월 차트에 그 금액이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 월 목표와 달성률

```
담당자마다 월 목표 금액을 정할 수 있게 해줘. 목표는 관리자만 정하고,
월간 실적 표에 목표 · 달성률 칸을 더해줘. 목표가 없는 사람은 "—" 로 보여줘.
```

## 3. CSV 내려받기

```
월간 실적 화면에서 고른 달의 계약 목록을 CSV 로 내려받게 해줘.
엑셀에서 한글이 안 깨지게 UTF-8 BOM 을 붙이고, = + - @ 로 시작하는 칸은 수식으로 실행되지 않게 막아줘.
```

## 4. 계약 고치기

```
잘못 넣은 계약을 지우지 않고 계약일 · 고객사 · 금액을 고칠 수 있게 해줘.
넣은 본인과 관리자만 고칠 수 있고, 서버(app/actions.ts)에서도 같은 권한을 확인해줘.
```

## 5. 알림 붙이기

```
1억 원 이상 계약이 들어오면 앱 관리자에게 axhub 알림을 보내줘. (AXHUB.md §5 참고)
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 지우기 같은 동작이 서버(app/actions.ts · lib/sales-store.ts)에서도 canDelete 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
