# 사내 공지

관리자가 공지를 올리고, 직원이 읽은 뒤 "확인했어요" 를 누르는 앱이에요. 관리자는 공지마다 누가 확인했는지 봐요.
로그인은 axhub 계정으로 하고, 공지와 확인 기록은 이 앱 전용 axhub DB 에 저장돼요.

## 할 수 있는 일

**직원**
- 공지 목록에서 안 읽은 공지를 먼저 봐요. 안 읽은 공지 중에서도 중요 공지가 맨 위에 와요.
- 공지를 열어 읽고 "확인했어요" 를 눌러요. 누른 뒤에는 확인한 시각이 보이고, 목록에서 "확인함" 으로 바뀌어요.
- 제목이나 본문으로 공지를 찾아요.

**관리자**
- 제목 · 본문 · 중요 표시를 넣어 공지를 올려요. 본문의 줄바꿈은 그대로 보여요.
- 공지마다 확인률(%)과 확인한 사람 수를 한눈에 봐요.
- 공지를 열면 "아직 안 본 사람" 과 "확인한 사람(확인 시각 포함)" 을 탭으로 나눠 보고, 이름 · 이메일로 찾아요.
- 잘못 올린 공지를 지워요. 누르기 전에 한 번 더 물어봐요.

## 화면

| 메뉴 | 주소 | 누가 |
|---|---|---|
| 사내 공지 | `/` | 로그인한 모든 사람 |
| (공지 읽기) | `/notices/번호` | 로그인한 모든 사람 |
| 공지 관리 | `/admin` | 관리자만. 다른 사람이 열면 "관리자만 볼 수 있어요" 가 보여요 |
| (확인 현황) | `/admin/번호` | 관리자만 |

## 확인률은 이렇게 세요

- **분모는 "이 앱에 한 번이라도 들어온 사람"** 이에요. 공지 목록이나 공지를 열면 그 사람이 명단에 올라가요.
  아직 앱에 한 번도 안 들어온 직원은 "아직 안 본 사람" 에도 보이지 않아요.
- 공지를 올린 뒤에 처음 들어온 사람도 분모에 들어가요 — 예전 공지도 읽어야 하니까요.
- 관리자도 직원과 똑같이 세요. 관리자가 자기 공지를 확인하지 않으면 확인률 100% 가 되지 않아요.
- 확인률은 소수점을 버려요. 한 사람이라도 남아 있으면 100% 가 되지 않아요.
- "확인했어요" 는 한 번만 기록되고, 처음 누른 시각이 남아요. 날짜와 시각은 모두 한국 시간이에요.

## 관리자는 누구인가요

axhub 가 "이 앱의 관리자" 로 알려 주는 사람이에요. 따로 설정하지 않아도 아래 사람은 자동으로 관리자예요.

- 이 앱을 만든 사람(앱 소유자)
- 워크스페이스(회사) 관리자

이 앱에서만 공지를 맡길 사람이 있다면, 그 사람을 워크스페이스 관리자로 올리지 마세요 (회사 전체 권한이 생겨요).
대신 앱을 일부공개로 두고 그 사람을 앱에 초대한 뒤(`axhub access invite`, [AXHUB.md §7](./AXHUB.md#7-로그인--권한--공개-범위)),
Claude 에게 이렇게 요청해요.

> "이 앱에 초대한 사람(app_role 이 app_member)도 공지 관리를 할 수 있게 해줘. `lib/notice.ts` 의 isManager 한 곳만 바꿔 줘."

단, 이렇게 하면 초대받은 사람이 **모두** 관리자가 돼요. 직원도 초대해서 쓰는 앱이라면 대신 이렇게 요청해요.

> "공지 관리를 할 수 있는 사람의 axhub 사용자 ID 목록을 관리자 화면에서 넣고 뺄 수 있게 해줘. 앱 소유자·워크스페이스 관리자는 지금처럼 늘 관리자로 두고."

직원이 이 앱을 쓰려면 앱 공개 범위가 그 사람을 포함해야 해요 (내부공개, 또는 일부공개로 초대).

## 저장하는 데이터

표 세 개에 저장돼요. 표는 앱이 처음 쓰일 때 자동으로 만들어져요.

- `notices` — 공지 한 건이 한 줄. 제목, 본문, 중요 표시, 올린 사람(axhub 사용자 ID · 이름), 올린 시각.
- `notice_reads` — "확인했어요" 한 번이 한 줄. 어느 공지를, 누가(axhub 사용자 ID), 언제 확인했는지. 공지를 지우면 같이 지워져요.
- `members` — 앱에 들어온 적이 있는 사람 명단(axhub 사용자 ID · 이름 · 이메일 · 처음 · 마지막 방문). 확인률의 분모예요.

확인률은 따로 저장하지 않고 화면을 열 때마다 계산해요. 데이터 백업 · 복원은 앱 콘솔의 백업 탭에서 해요.

## Claude 에게 이렇게 바꿔 달라고 해 보세요

axhub 플러그인이 설치된 Claude Code 를 이 폴더에서 열고 말로 요청하면 돼요.

- "공지를 올리면 직원 모두에게 axhub 알림을 보내 줘"
- "확인률 분모를 앱 방문자가 아니라 회사 조직도 전체 인원으로 바꿔 줘"
- "아직 안 본 사람에게 다시 알림 보내기 버튼을 확인 현황 화면에 추가해줘"
- "올린 공지의 제목과 본문을 고칠 수 있게 해줘. 고치면 확인 기록을 지울지 물어봐 줘"
- "공지에 확인 마감일을 정하고, 마감이 지난 안 읽은 공지는 빨갛게 보여 줘"

## 직접 돌려 보기 (개발자용)

```bash
npm install
npm run setup     # .env.local 만들기
npm run db:up     # 로컬 Postgres (Docker 필요) → .env.local 의 DATABASE_URL 줄 앞 # 지우기
npm run dev       # http://localhost:3000
```

내 컴퓨터에는 axhub 로그인이 없어서 화면이 "로그인할 수 없어요" 로 보여요. 실제 공지 · 확인은 axhub 에 배포한 뒤 확인해요.
배포는 Claude Code 에서 `/axhub:deploy`. DB · 알림 · 공개 범위 같은 axhub 기능은 [AXHUB.md](./AXHUB.md) 에 모여 있어요.

| 검사 | 명령 |
|---|---|
| 공지 규칙 | `npm run check:logic` |
| 디자인 규칙 | `npm run check:design` |
| 타입 · 린트 | `npx tsc --noEmit` · `npm run lint` |
