# 시작용 프롬프트 모음

이 앱은 사내 공지·읽음 확인 앱이에요. 아래 요청을 그대로 복붙하거나 살짝 바꿔서 Claude 에게 말해 보세요.
고칠 곳의 구조는 CLAUDE.md 의 "이 앱" 절에 정리돼 있어요.

## 1. 배포하고 확인하기

```
axhub 에 배포하고 성공했는지 확인해줘. 그다음 공지 관리 화면에서 공지를 하나 올리고,
사내 공지 화면에서 "확인했어요" 를 누른 뒤 확인 현황에 내 이름이 보이는지 어디서 확인하면 되는지 알려줘.
```

## 2. 새 공지 알림

```
공지를 올리면 앱을 쓰는 직원 모두에게 axhub 알림을 보내 줘. 중요 공지는 제목 앞에 [중요] 를 붙여 줘. (AXHUB.md §5 참고)
```

## 3. 안 읽은 사람에게 다시 알리기

```
확인 현황 화면에 "안 본 사람에게 다시 알리기" 버튼을 추가해줘.
누르기 전에 몇 명에게 보내는지 한 번 더 물어봐 줘.
```

## 4. 확인률 기준 바꾸기

```
확인률 분모를 "앱에 들어온 사람" 이 아니라 회사 조직도에 있는 전체 인원으로 바꿔 줘.
아직 앱에 안 들어온 사람도 "아직 안 본 사람" 에 보이게 해줘.
```

## 5. 공지 고치기

```
올린 공지의 제목·본문·중요 표시를 관리자가 고칠 수 있게 해줘.
내용을 고치면 기존 확인 기록을 지우고 다시 확인받을지 물어봐 줘.
```

## 6. 배포 직전 점검

```
배포 전에 점검해줘:
- npm run check:logic · npm run check:design · npx tsc --noEmit 이 통과하나?
- 관리자만 해야 하는 동작이 서버(app/actions.ts)에서도 isManager 로 막혀 있나?
- DB 쿼리에 사용자 입력을 문자열로 이어붙인 곳이 있나? (tagged-template 만)
- console.log 남은 거 있나?
```
